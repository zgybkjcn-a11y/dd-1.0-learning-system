## 1. 目标、范围和成功标准

近期目标：让已经开发的能力形成可复现、可回退的交付；让一章的少量教材片段可以可靠检索、引用和回查；随后完成“阅读—理解—练习—显式保存错题—到期复习”的连续体验。

| 阶段 | 要达到的结果 | 不可据此推断的结果 |

## 4. 技术实施路线

### 4.1 沿用现有架构

```mermaid
flowchart LR
    U[现有家庭与主站入口] --> G[固定网关：档案与书章校验]
    G --> S[学习服务]
    S --> P[服务器固定的有效片段库]
    S --> L[既有页级定位路径]
    P --> E[片段 ID / 来源 / 双页码 / 复核版本]
    L --> E
    E --> T[既有六方法 Tool 候选]
    T --> C[原生 citation 与正文引文回链]
    C --> R[再次授权校验后的教材原页]
```

优先提取独立脚本中可复用的纯校验/查询逻辑为业务模块，再接服务和 Tool；模块名由 A07 确定，不将脚本目录变成隐式运行时依赖。新增模块必须进入发布白名单，并验证旧 release profile 仍能使用。

### 4.2 证据类型与查询状态

| 类型/状态 | 可以展示什么 | 必须保持的边界 |
| --- | --- | --- |
| `page_location` / `locations_only` | 页标题、来源、双页码、原页链接 | 不含未经核验的教材引文，不声称回答得到支持 |
| `local_explanation` | 明确标注的本地理解参考及其自身身份 | 不是教材原句，不新授予判分资格 |
| `assistant_reviewed_excerpt` | 有效限定片段的完整引文、审核身份、来源回链 | 非整页/教师审核；试点继续 `can_answer_from_textbook=false` |
| `no_evidence` | 在已检查范围内没有可用证据 | 不扩大到“教材不存在该知识”；同时报告检索覆盖是否完整 |
| 低相关/检索不完整/服务失败 | 说明本次不足的具体类别和可执行恢复方式 | 不能都折叠成“无证据”；字段名由 A05/A07 契约冻结 |

服务器选择材料路径、可信清单哈希、允许的书章和当前时间；模型不得传文件路径、任意 URL、学习者 ID、复核结论或 `as-of`。来源身份不含学生身份，也不提供访问权限。返回前及打开原页时仍检查当前档案范围/revision；停用、到期、换文、换源、换复核版本后，缓存和旧证据不能继续获得可引用资格。

引用链的最小承诺是“本次返回的完整引文确实来自这些有效片段”。断言是否回答了问题、任意改写是否成立、真实模型是否遵循提示，需要独立验证，不能以 ID/hash 一致替代。

### 4.3 检索改进路线

先冻结 A06 评测，再处理 A05。先用接口/源码和合成服务验证现有 WebUI 查询接口是否支持可靠的章节 metadata 前置过滤；不能为探测接口偷偷触发真实 embedding。

- 若支持：书册授权仍在查询前，章节过滤进入候选召回，返回后再次校验版本/页码并去重；保留相关性排名，展示排序另处理。
- 若不支持：5 片段试点在已核对本地库中先按范围过滤，再做确定性词法检索/评分。证明的是这个有界库的检索能力。
- 旧整册 top40 后过滤路径必须显式标记检索覆盖不完整；增加 k 只能作为实验，不构成章内召回问题的完整修复。超出试点范围的真实检索验收留待条件允许，不报全书修复完成。

- **验收/停止：** 报告所有分母、漏检和弃判；样本量、各类误差门槛在采样前冻结，不能从当前资料虚定准确率。先公开或合成材料；真实学生资料未获相应范围不得访问/外发；高风险错误未解决则保持人工确认，不自动判分。

### C03 完整恢复、删除增量和费用对账

- **启动条件：** B07/B08；在学生数据扩大、跨系统恢复需求或付费调用计划出现时启动，相关存储/维护范围明确。启用付费调用前先设计水位，不能事后补猜历史。
- **步骤/产物：** 依[完整恢复设计](../open-webui-reuse/07-MONITORING-RECOVERY-PLAN-2026-11-05.md)覆盖七类组件；备份后删除增量、在途调用与费用水位在恢复开放前重放；WebUI 聊天与学习 provider 分账。角色：维护执行者。
- **验收/停止：** 全新隔离目标验证对应版本、删除不复活、未知费用不清零；独立记录完整系统 RPO/RTO。缺任何关键水位或组件禁止开放恢复入口；不把基本学习库演练当完整恢复。

### C04 多学科内容扩展

- **启动条件：** B01–B04 的小批内容方法可用，有学校当前在学章节和适用新版依据。角色：内容复核者 + 家长 + 工程执行者。
- **步骤/产物：** 每次一门一小单元；建立字词/拼音/引文、历史事实、地理图例、生物示意等学科专属核验表；复用来源/版本/审核/覆盖清单。
- **验收/停止：** 每批实际通过范围、未核内容和教学能力分别显示；不得用数学算例检查替代其他学科核验。找不到可靠来源或复核者即保留阅读范围；用户举的“光合作用”是目标场景示例，未核实的 p.29–37 不能写成真实页码。

### C05 重新评估 RAGFlow 全栈与媒体组件

- **启动条件：** A05/A06/B10 已有瓶颈数据或教师/家庭明确提出教学需求；不因项目流行而启动迁移。
- **步骤/产物：** 比较现有服务与候选在同一小样本上的质量、维护成本、资源、许可、隐私和退出成本；必要时做隔离小试验。角色：工程执行者/范围决策者。
- **验收/停止：** 决策记录可以是“继续现有方案”；只有收益证据和迁移/回退路径明确才另立实施范围。当前计划不包含整套 RAGFlow、课程平台、全图谱重建或媒体流水线安装。

## 7. 质量与验收标准

### 7.1 引用试点的预定指标

以下为 **A06 冻结前提出、执行时原样冻结的验收目标**。A06 已测基线（召回 2/20、拒绝 2/10，未达标），见[验证报告](../verification/A06-retrieval-evaluation-2026-11-07.md)。40 问规模只衡量 5 片段试点，不能外推全书、跨学科或真实用户准确率。

| 指标 | 计算口径 | 试点目标 |
| --- | --- | --- |
| 相关证据召回@4 | 20 个可回答问题中，top4 命中至少一个预期有效片段的问题数 / 20；多证据题另报必需证据覆盖 | ≥18/20；另报逐概念表现 |
| 无依据拒绝 | 10 个同范围、语料不支持的问题中，不返回可引用片段的数量 / 10 | ≥9/10；每个误命中人工复核 |
| 范围隔离 | 10 个章外/册外/档案不允许案例泄漏数 / 10；另覆盖查询中换档案 | 0 泄漏；不以相关性不足掩盖授权失败 |
| 来源与双页码准确 | 实际返回的所有引用中，ID/源版本/书内页/PDF 页正确数 / 返回引用总数 | 100%；同时报告总数，零输出不算通过 |
| 完整引文一致 | 引文与本次有效片段全文一致的数量 / 全部引文 | 100%；篡改/杜撰 ID 必须拒绝 |
| 失效与故障区分 | 到期、撤回、换文、坏源、超时、低相关等契约案例 | 每类预期行为全部通过；不混成“教材无内容” |

独立性指问句不与开发词项共同设计，按表达/意图组分开；因仅有 5 个共同片段，不能声称语料/概念完全独立。若执行者已看过测试失败并用于调参，应记录暴露，另补冻结表达组。阈值改动需先留理由及新版本，再重测，保留原结果。

### 7.2 分层验证与证据复用

| 层 | 验证内容 | 执行时机 |
| --- | --- | --- |
| 文档/数据 | 25 个任务 ID、链接、依赖无环、数值、清单字段和状态一致 | 计划/清单变更后 |
| 单元/合成契约 | 证据、身份、范围、失败、撤回/过期、并发幂等 | 对应业务变更后 |
| 干净环境 | 声明依赖、无私有材料、必需套件不静默跳过 | A03 与依赖/夹具变化后 |
| 隔离集成 | 网关、临时 DB、固定 WebUI 原生 loader/citation、release profile | A07/A08 或相关契约变化后；断网、无正式 data |
| 浏览器 | 主站桥接、手机布局、草稿/练习保护、引用/原页/打印 | 相关 UI/静态或接口变化后 |

已有 117 项页级测试、29 项片段测试与断网 loader 证据可用于对应未变化候选；不能把测试数量相加当全新验收，也不因写文档重跑全套。出现新修改、失败或未解决风险时再扩大必要范围。

## 8. 发布、回退与材料管理

### 8.1 每个候选必须具备的交付包

交付包包含：范围/任务 ID、输入基线、源码与文件哈希、相容组件组合、变更说明、必要测试结果、部署差异、回退操作、失败停止条件及已知限制。包含私有数据的材料在忽略目录并单独备份；公开清单只保存必要版本/哈希与恢复位置说明。

新批次统一使用 `learning_data/verification/<task-id>-<YYYYMMDD-HHMMSS>/` 保存运行证据，目录必须新建且不存在。目前 `prepare_main_study_samples.py` 和片段样本脚本会覆盖固定输出；执行前先参数化或在新材料副本上运行，禁止覆盖旧的成功/失败报告。

### 8.2 三条独立交付路径

| 路径 | 执行顺序 | 失败处理 |
| --- | --- | --- |
| 静态样本 | 精确候选/资源 → 隔离探针 → 核对当前 alias → 校验代理配置 → 按既有有效范围切换 → 发布后检查 | 仅恢复本次保存的静态/alias 集合；不换服务/Tool/卷 |
| 服务与片段 | 新镜像/白名单/只读材料包 → 旧 Tool 兼容验证 → 受控更新对应服务 → 验证新字段与材料有效性 | 关闭片段能力或恢复相容服务；有迁移时执行已验证方案，不盲降数据库 |
| 既有 Tool | 相容服务就绪 → 精确旧 ID/哈希准备 → 窄范围 CAS 升级 → 原生验证 → 更新清单 | 先回退 Tool 到受支持版，再决定服务回退；冲突停止，不覆盖他人更新 |

这些是未来操作次序，不是本轮发布命令，也不自动扩大正式数据库访问范围。已有授权适用时不重复询问；授权不足时先完成候选与回退包，并明确指出需要覆盖的具体动作。

### 8.3 源码提交与不提交内容

可纳入审阅：通用服务/Tool/脚本、原创合成测试夹具、非敏感说明、契约、许可/署名、计划与台账。具体依赖按 A02 分组，测试/说明与对应代码一起审阅。

不纳入公开源码：教材 PDF/原页图/已核片段正文包、学生资料、运行数据库/卷、Cookie/密钥/环境文件、含身份截图及原始日志。本地材料缺备份不能靠“未提交”保证可恢复；B07 单独落实备份。

## 9. 风险、变更与完成定义

| 风险 | 发现信号 | 应对及负责项 |
| --- | --- | --- |
| 版本清单与在线状态漂移 | 别名/镜像/Tool 哈希不一致 | A01 记录差异，A08/A09 拒绝不匹配更新 |
| 评测过拟合 | 新表达漏召回、看失败后加词宣布通过 | A06 冻结/版本化，A05 报未覆盖范围 |
| 过期或撤回片段继续展示 | 缓存或历史日期绕过检查 | A07 每次有效性检查与旧证据失效；B10 缓存同规则 |
| 片段被误作标准答案 | UI/Tool 声称教材回答、教师确认 | A07 保持能力标记；B03 区分审核类型；C01 实测 |
| 内容增长快于审核 | 批量 OCR/题量增长但审核不全 | B02/B04 先小批，问题未解不计通过 |
| 备份恢复遗漏附件或删除 | 同期写入、缺组件/水位 | B07 一致性演练，C03 扩展完整恢复 |
| 外部条件导致停滞 | 无家长反馈、人工复核或模型许可 | 工程子项可先验收；转做依赖已满足任务，不伪造闭环 |

任何新增范围须登记目的、任务 ID/子批次、依赖、影响和验收；超出本计划的大型迁移另立方案。完成某项需：产物可审阅、必要检查通过、失败/回退路径成立、证据/版本可定位、台账同步。涉及上线或实际反馈的任务在对应证据出现前只标工程就绪或待反馈，不能只因文档、脚本存在而标全项完成。
