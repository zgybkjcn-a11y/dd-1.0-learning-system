## 修复及可复核行为

| 场景 | 原行为或缺口 | 本次行为 |
| --- | --- | --- |
| 编辑器缺失、重复、禁用、只读、隐藏、inert或类型不支持 | 入口仍可用，部分路径仅在点击后检查 | 只认唯一当前可用的DIV/textarea，停用受影响填入并提示，不寻找其他输入框 |
| 等待家庭检查时替换编辑器、切换URL或新写草稿 | 快捷请求保留旧编辑器引用 | 填入前重查同一元素、地址和空草稿，变化就停止，自动发送0 |
| 网络失败 | 面板输入被清空且不能恢复 | 在本页内存按账号/档案/revision暂存并隐藏，清空引用；重连完整核验后只恢复同身份草稿 |
| 切档或身份失效 | 旧输入清空，主站历史聊天缺少持续提示 | 丢弃暂存及旧引用，保留用户主站草稿，提示历史聊天不会自动切换并提供新聊天链接；关闭面板也响应切档信号 |
| 填入焦点 | dialog关闭事件把焦点从编辑器拉回入口 | 成功填入停留在编辑器；普通Esc关闭回到原入口 |
| 上游缩放与触屏 | 原生viewport含maximum-scale=1；部分快捷按钮偏小 | 去掉缩放限制并保留其余设置，移动端伴学按钮最小44px，输入字号16px |
| 家庭页面契约失效 | 缺少章节控件可能报错、旧继续入口残留 | 清除旧共享范围/入口，显示同步暂停提示，无未捕获异常 |

暂存只在当前页面内存，未写localStorage、IndexedDB或服务器；刷新/关闭会丢弃，界面明确提醒。身份不明时不展示暂存文本或导出旧证据。已有聊天草稿由用户确认，扩展不读取或改写历史聊天，也不宣称能清除宿主聊天记录。
