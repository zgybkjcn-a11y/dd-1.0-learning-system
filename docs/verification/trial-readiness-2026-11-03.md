# T23 真实试用准备包（未启动）

日期：2026-11-03（Asia/Shanghai）  
状态：**blocked；仅完成准备，不构成真实试用或学习效果结论**

## 目的和边界

本文件把 T23 的真实试用前检查、观察字段和停止条件固定下来。当前没有真实学习者、真实资料、真实 Open WebUI Tools/回调、真实 OCR/模型额度或正式上线授权，因此不创建参与者记录、不发送资料、不发起付费调用，也不填写虚构的 7–14 天日志。

试用必须使用独立测试账号、独立数据目录/卷和可撤销的 provider 配置；正式 Open WebUI、现有 `data/`、生产通知和未授权外发保持阻断。试用结果只能说明本批参与者和观察窗口内的可用性与初步趋势，不能替代 30 天调度间隔或长期保持观察。

## 启动前签核清单

只有每项都有可审阅证据，T23 才能从 blocked 进入 in_progress：

- [ ] 当前会话明确授权试用范围、参与者数量、时段、资料外发范围、provider 预算和停止权限。
- [ ] 学习者/监护人知情同意、删除请求路径、保留期限和人工复核联系人已登记；证据使用脱敏 ID。
- [ ] 提供脱敏整卷/参考判定集和人工审核人；质量报告约定全量题、失败页、弃判、精确率/召回率、耗时和费用字段。
- [ ] 隔离 Open WebUI 测试账号完成 Tools 注册、可信回调和浏览器链路探针；适配器身份映射与学习者授权通过。
- [ ] provider/OCR 使用明确版本、超时、预算和出网范围；默认 mock 仍保持关闭真实试用结论的语义。
- [ ] 独立 Compose project、数据库/附件备份、恢复演练、日志脱敏和管理员访问范围已复核；没有挂载正式 `data/`。
- [ ] 参与者遇到答案泄露、跨学习者数据、错误成绩、无法删除或 provider 失控时的立即停用和回滚联系人已确定。

## 观察窗口和记录字段

观察窗口为连续 7–14 个自然日；每日记录实际发生的事件，不补写缺失日期。每条记录只使用脱敏参与者/题目 ID，并保存服务端事件 ID、版本和时区：

| 维度 | 必记字段 |
| --- | --- |
| 规模 | 学习者数、文档/页/题数、独立/辅助/待复核样本数 |
| 导入质量 | 失败页、分题完整性、人工参考判定、误判/漏判、弃判和待复核比例 |
| 学习行为 | 独立正确率、辅助完成率、重复错因、逾期率、实际用时、提示/素材暴露 |
| 状态安全 | 跨学习者访问尝试、挑战重放/过期、同键异载荷、迟到 worker、重复调度 |
| 运行质量 | provider 版本/调用次数、错误/超时、队列等待、端到端耗时、实际费用 |
| 反馈 | 参与者可用性问题、人工修订、题目/变式问题、删除/撤回请求和处理时间 |

## 通过和停止条件

试用报告必须把独立、辅助和待复核结果分开，列出分母、缺失数据和未覆盖题型；不得用 mock 或小样本替代真实质量结论。出现以下任一情况立即暂停写入并保留现场：跨学习者数据、答案或原始资料泄露；未经授权外发或付费调用；确认/答案挑战绕过；成绩或调度重复生效；删除/恢复无法对账；连续 provider/存储故障造成不可恢复状态；人工审核发现可投放题无解、答案错误或明显超纲。

窗口结束后由人工审核人出具问题清单和修订决定，再决定是否扩大范围。未完成真实窗口、人工抽检或问题复验前，T23 保持 blocked，Goal 不得标记 complete。
