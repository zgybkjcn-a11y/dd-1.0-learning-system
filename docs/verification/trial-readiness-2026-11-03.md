# T23 真实试用准备包（未启动）

日期：2026-11-03（Asia/Shanghai）  
状态：**blocked；仅完成准备，不构成真实试用或学习效果结论**

## 目的和边界

本文件把 T23 的真实试用前检查、观察字段和停止条件固定下来。当前没有真实学习者、真实资料、真实 Open WebUI Tools/回调、真实 OCR/模型额度或正式上线授权，因此不创建参与者记录、不发送资料、不发起付费调用，也不填写虚构的 7–14 天日志。

**真实验收先在隔离预发布环境做，不要求也不应先升级生产。** 真实指运行真正的 Open WebUI 浏览器、Tools、可信回调以及配置好的模型/OCR 路径；这些组件连接到隔离 Learning Service、合成数据和独立凭据即可验证技术集成。生产 Open WebUI、生产数据与生产服务都不参与。

可复用已完成探针的隔离 Open WebUI 实例，也可用与目标版本相同的镜像另起 disposable/staging 实例；与它配对的 Learning Service 使用新的 Compose project、独立数据库和附件卷、独立网络与凭据。隔离 Open WebUI 和 Learning Service 必须使用同一测试身份映射和同一个 staging 服务地址。启动前确认该 project 没有挂载现有 `data/`、没有生产 API/存储/通知路由，且出站只允许明确批准的模型/OCR endpoint。销毁演练时仅清理这个 staging project。

模型连接可选择自托管/本地模型以避免新增付费调用；若使用付费 provider，必须先限定 provider、模型、预算、重试上限和出网范围并获得授权。首先用合成题图/答案跑完整界面和回调；使用真实学习者材料或把其发送到外部 provider 之前，另行完成去标识化审查和资料外发授权。试用结果只能说明本批参与者和观察窗口内的可用性与初步趋势，不能替代 30 天调度间隔或长期保持观察。

这条预发布验收与正式部署是两个独立门槛：预发布的 Tool 注册、真实模型 tool call、浏览器最终可信回调和 provider 集成通过后，仍不能据此认为生产已升级或授权切换。生产切换需要单独审阅具体镜像/配置/迁移/备份与回滚清单并获得明确授权。T23 真实试用还需要参与者同意、人工抽检及连续观察授权；可以在隔离预发布环境进行，不是验证代码集成的前置条件。

## 观察窗口和记录字段

观察窗口为连续 7–14 个自然日；每日记录实际发生的事件，不补写缺失日期。每条记录只使用脱敏参与者/题目 ID，并保存服务端事件 ID、版本和时区：

| 维度 | 必记字段 |
| --- | --- |
| 规模 | 学习者数、文档/页/题数、独立/辅助/待复核样本数 |
| 导入质量 | 失败页、分题完整性、人工参考判定、误判/漏判、弃判和待复核比例 |
| 学习行为 | 独立正确率、辅助完成率、重复错因、逾期率、实际用时、提示/素材暴露 |
| 状态安全 | 跨学习者访问尝试、挑战重放/过期、同键异载荷、迟到 worker、重复调度 |
| 运行质量 | provider 版本/调用次数、错误/超时、队列等待、端到端耗时、实际费用 |
| 反馈 | 参与者可用性问题、人工修订、题目/变式问题、删除/撤回请求和处理时间 |

## 通过和停止条件

试用报告必须把独立、辅助和待复核结果分开，列出分母、缺失数据和未覆盖题型；不得用 mock 或小样本替代真实质量结论。出现以下任一情况立即暂停写入并保留现场：跨学习者数据、答案或原始资料泄露；未经授权外发或付费调用；确认/答案挑战绕过；成绩或调度重复生效；删除/恢复无法对账；连续 provider/存储故障造成不可恢复状态；人工审核发现可投放题无解、答案错误或明显超纲。

窗口结束后由人工审核人出具问题清单和修订决定，再决定是否扩大范围。未完成真实窗口、人工抽检或问题复验前，T23 保持 blocked，Goal 不得标记 complete。
