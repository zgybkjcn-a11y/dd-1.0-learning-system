## 工程实现

源码：`scripts/textbook_passage_sample.py`；测试：`tests/test_textbook_passage_sample.py`。脚本没有导入进服务启动路径，也不添加运行时打包依赖。

1. 调用者显式传入已核对清单的 SHA256；不自动相信旁边可一起修改的校验文件。
2. 加载时核对当前目录身份、书章与双页码、实际 PDF 字节、原页图片、片段文字、上下文、复核绑定、数学检查报告及其核验脚本哈希。哈希绑定证明一致性，不能证明人工填写的复核结论正确。
3. 待核对、停用、过期、未来复核或仍有问题的片段不参与查询。资料损坏或绑定不一致直接拒绝候选。输出仍标记 `teacher_reviewed=false`、`fully_reviewed_page=false`、`eligible_as_grading_basis=false`。
4. 查询前按当前年级、书册和章节过滤；显式词项匹配只返回最多四个候选片段。范围外或无词项命中则返回空证据，不静默改查别册。
5. 片段 ID 绑定来源位置、文本/上下文/原图与完整复核记录。正文输出仅允许 `direct_quote`，引文必须与本次返回片段的全文一致；杜撰 ID、旧复核 ID、增加文字、自由答案或未绑定结论均不通过检查。
6. 预览的每个正文引用按证据身份链接到原页来源，原图链接仅使用本地相对路径。

审核清单固定 SHA256：`d1bf256db814afcf35ff22f28ad32fd4577b4608e12f9d069b7f72cfc8cacd63`。
