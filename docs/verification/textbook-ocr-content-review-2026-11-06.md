# 教材 OCR：转写与内容正确性分别核验

用户要求的第二层核验已加入：与图片相符只证明转写，数学结果还必须独立计算，条件、单位、图形和上下文也必须完整。语文事实、专名等不能凭语句通顺自动通过。本次没有调用外部模型或新增 OCR。

## 真实教材抽查

直接查看人教官方二年级数学下册图片后，对以下三个片段逐项记录复核和计算。记录中的图形说明是明确标记的转述；练习答案是独立推导，不冒充教材印刷答案。复核人为 Codex 助手，不是用户或教师人工签署。

| 原文位置 | 独立内容核验 | 范围 |
| --- | --- | --- |
| 书内第10页，9根小棒摆正方形 | 两个独立正方形用8根，余1根；9=4×2+1，0≤1<4；商为“个”，余数为“根” | 图形和示例片段 |
| 书内第14页，13=4×3+1 | 4×3=12，12+1=13；另验除法余数1小于4，不能只看等式成立 | 横式及对应竖式关系 |
| 书内第14页，11盒酸奶每4盒装一袋 | 装2袋用8盒，余3盒；11=4×2+3，0≤3<4；商为“袋”，余数为“盒” | 完整第1（1）题及独立推导答案 |

同时发现并保留三处识别问题：

- 数学第8页“日晷”丢失“晷”，OCR 变成“圭表和日被称为”。已对照图片标记，历史知识陈述仍需独立事实依据。
- 语文目录“揠苗助长”丢失“揠”。已记录正确标题；这不等于整篇课文或全部字词通过审核。
- 数学第14页竖式被串成“除数413”，其他竖式出现“4/15”等文字。需恢复除数、被除数、商、积、余数的空间关系，不能当作普通分数。

原 OCR 和原图均保留，纠正与推导另存。[机器可读复核记录](../../learning_data/verification/family-textbooks-20261105/sample-content-review.json)可由 `python3 scripts/verify_textbook_samples.py` 重验图像/识别结果校验值与独立计算；脚本不会自动重新做视觉判断、批准全页或发布题目。

## 防止误放行

24项题目质量测试和10项OCR导入测试通过，覆盖：忠实抄下错误算式仍拒绝、正确算式缺原图审核仍隔离、余数越界、除零、单位/条件/图形未核验、只审核一个裁剪行、跨行拼接数字、题干/图像/答案改变、仅写“已审核”标记、缺页/换页/改文以及用重复OCR代替内容核验。这些合成测试验证审核机制，不能证明教材全书正确。

OCR 全文入库需要逐页转写复核和独立内容复核，报告绑定原PDF、每页文本与报告校验值。入库用途仍仅为教材阅读检索，不能替代题目与答案审核。原生 PDF 提取同样可能丢失公式和图形，也不得直接作为标准答案。
