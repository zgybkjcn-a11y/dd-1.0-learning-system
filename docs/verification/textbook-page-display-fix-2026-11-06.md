# 数学教材原页展示与放大链接修复

用户反馈七年级上册第144、115页图形丢失、字母和公式乱码、打开教材链接不对应。检查确认：索引使用的PDF本身完整，但提取文字时嵌入字体中的斜体变量被映射为汉字，指数/分式/图形丢失布局，页脚数字还可能倒序。此前链接仅打开人教阅读器首页，没有定位到命中页。

现已统一修改当前开放的三册数学教材（二上、七上、七下）：向量检索定位页面，界面直接显示同一版本PDF渲染的完整原页，停止展示乱码文字。“放大查看第 N 页原图”打开已加载的同一图片，不再跳到官方首页。同页多个命中合并展示；图片不可用时提供重试，不退回乱码文字或错误链接。切换档案、册次、章节或重新检索时释放旧图片，迟到响应不能恢复旧结果。

原页接口 `/api/v1/textbooks/{book_id}/pages/{printed_page}/image` 继续通过既有家长登录、当前档案及上下文版本校验。只接受目录中当前年级的册次和书内页码，PDF校验值必须与建立索引的来源一致。三本固定PDF只读挂载到家庭API的 `/opt/dd-textbooks`；没有新增公开文件目录，不读取任意路径或请求外部阅读器。响应为PNG，浏览器使用带现有身份与上下文的请求获取，再建立本页临时放大链接。

页码：七上第115页对应PDF第122页，第144页对应PDF第151页；二上第10页对应PDF第15页；七下第10页对应PDF第17页。页码映射与来源校验记录在 [rendered-page-checks.json](../../learning_data/verification/textbook-page-fix-20261106/rendered-page-checks.json)。已实际查看第115页变量、上标和等式，以及第144页杠杆图及 n、l、x 标注，均保留原排版。

验证：12项教材检索/原页/网关测试，以及50项浏览器、登录、家庭功能和候选包测试通过。包括按年级隔离、错误/缺失PDF拒绝、失效上下文拒绝、页码对应、手机390px和桌面1280px、图片加载失败后重试和放大链接点击。另外用真实七上PDF的第115、144页在两种宽度完成浏览器实测，图像1044×1474、放大可打开、无横向溢出、无浏览器脚本错误。[实物浏览器记录](../../learning_data/verification/textbook-page-fix-20261106/real-page-browser-report.json)。首次实物探针未启用合成家庭模式，无法定位档案按钮；修正探针配置后完成，业务代码无需调整。

构建使用52文件白名单候选、已锁定本地依赖、禁网构建。候选 `dd-v1-family-textbook-pages-20261106`，镜像 `sha256:4c068b2200c36d087dd520682aa2121447b0eedaf40484e9f57c4ed037e2d464`。Compose为 `learning_data/deployments/family-math-20261105/compose-textbook-pages-20261106.json`。上线前在线备份 `family-textbook-pages-preupdate-20261106` 的SHA256和SQLite完整性通过；仅更新家庭API、worker、gateway，代理和原WebUI容器ID及启动时间未变，原网络/TLS/卷保持。

上线后验证：实际UI包含原页展示和新放大链接；部署源码与候选一致；容器内渲染的两张问题页与本地核验图像SHA256完全一致；API健康、HTTPS证书与登录跳转通过。前后账号1、档案2、绑定1、浏览器会话记录2、学习会话51、作答/判分50、错题0、provider0一致。见 [deployed-verification.json](../../learning_data/verification/textbook-page-fix-20261106/deployed-verification.json)。浏览器功能验证使用合成身份，未读取真实家长Cookie；用户已有页面需刷新后重新检索。
