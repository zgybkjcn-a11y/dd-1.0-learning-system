# 试卷与作业上传：自动识别错题并归入错题本

统一实现契约见 [设计开发总文档](DESIGN_DEVELOPMENT_SPEC.md)，开发顺序见 [任务与验收清单](IMPLEMENTATION_BACKLOG.md)。本专题保留导入细则。

日期：2026-11-02。需求增补 U1；主规划 R2 的输入与错题收集范围扩展。

状态：**设计细则已落实为独立服务的 V1 上传、页资产、候选复核和确认实现；真实 OCR/判错质量与学生文件验收仍待外部条件。** 当前代码保留原件、失败页、候选 revision、可信批量确认和来源回查；确定性 mock 只产生待复核结果，不代表真实学科质量。证据见 `docs/verification/`，不得把合成资料当作真实学生文件。

## 1. 用户目标与首期交付

学生或监护人上传整份试卷、作业 PDF 或多张照片后，系统自动整理题目、学生作答、批改痕迹和疑似错题，保留原卷定位；通过一次批量确认形成正式错题记录，并衔接归因、讲解与复习。

- 首期支持 JPG/PNG 多图与 PDF，覆盖已批改试卷、已批改作业，以及有适配参考答案的未批改材料。照片可排序、旋转、补拍和替换；未支持格式明确提示，不默默跳过。
- 上传前在可信界面选择学习者、学科、试卷/作业类型；完成日期可选，未知就保留未知。纸面姓名和模型推断只作为核对线索，不自动改变学习者归属。
- 原件、分题裁剪、学生笔迹、教师批改与标准答案分别保存。用户能从任何错题回到来源文件、页码和题号。
- 首期将候选自动保存到“待确认”收集箱；支持一次确认所有已检查候选，不要求逐题重新录入。无法判定项进入待复核区，不冒充已确认错题。
- 仅清晰、边界明确且判定依据可核验的范围进入首期正式导入；复杂题仍可上传、查看、手动分题和整理，不承诺无人复核的全题型判分。

这一模块属于核心学习入口。实施优先级高于扩展动画模板、视频导出和全学科视觉内容。

## 2. 完整流程

```text
选择学习者、学科及资料类型
             ↓
上传多图/PDF＋可选参考答案
             ↓
文件检查、质量提示、排序、页面预处理
             ↓
版面识别 → 分题/跨页关联 → 原题、作答、批改分别转写
             ↓
按证据判定：正确 / 错误 / 部分错误 / 未作答 / 无法判定
             ↓
收集箱：原图与识别结果对照、修正分题/转写、复核争议
             ↓
可信界面批量确认 → 幂等导入正式错题本
             ↓
知识点映射与错因假设 → 按需图解/交互教学 → 后续独立复测
```

上传返回导入任务 ID，长任务在独立 worker 中执行。界面展示已处理页数、识别题数、候选数、待复核数、失败页和实际已入库数。上传成功、识别完成、确认完成、归因完成是不同状态。

每页保留覆盖情况；无法分题的整页必须显示“识别不完整”。不能用已经识别出的题数作为总题数来宣称没有漏题。

## 3. 怎样判断错题

| 材料情况 | 自动处理 | 必须保留的边界 |
| --- | --- | --- |
| 有老师批改的试卷/作业 | 识别勾叉、得分/扣分、修改与评语，关联到题号和具体小问 | 红色不是错误的充分证据；对勾、勾叉相叠、页边记号、订正都可能有歧义 |
| 有参考答案的未批改材料 | 核对卷版本、题号、小问、题干和选项顺序，逐题比对；支持题型用规则校验 | 答案不匹配、缺答案、单位/定义域不清或与批改冲突时进入复核 |
| 无参考答案的未批改材料 | 模型提出候选解与理由；适用题型调用确定性校验 | 模型自报“正确率高”不能代替验证；校验未覆盖的题只能作为待复核建议 |
| 解答题/证明题/作文等 | 提取已有批改证据、评分点和疑似问题 | 原始步骤不完整时不补造学生思路；首期无批改且无可靠评分依据的主观题不自动裁决 |
| 空白、涂改、跨页答案或图形缺失 | 标出未作答、订正候选、关联缺失或画面不清 | 空白不一律当错题；看不清不判错；订正答案不覆盖原始错误作答 |

判定字段与错误归因分开：`verdict` 表示题目结果，`evidence` 表示依据，`verification_status` 表示是否核验，`error_types` 表示待验证错因。教师标记只能提供结果线索，不能直接证明“概念不懂”或“粗心”。

保留每个关键证据的页码、区域坐标、原始识别值和版本。转写、分题或答案映射变更后，相关判定与确认失效，重新校验；后台旧结果不能覆盖新修订。

## 4. 分题、复核与入库交互

- 页面分区区分题干、共用材料、选项、答题区、教师批注与标准答案。小问有独立标识，同一大题保留父子关系；跨页题能关联多个区域，共用材料不得丢失。
- 复核界面左侧显示原卷并高亮相关区域，右侧展示题干、原作答、批改依据与拟判结果。支持改文字、合并/拆分题、重新指定答案区、补页、标记“非题目”或“无法判断”。
- 允许筛选疑似错误、部分错误、未作答、无法判定及全部题目；正确项也可抽查，便于发现漏识别的错题。
- 用户确认的是明确展示的资源版本、选中题目和判定依据。确认动作不是无条件批准模型生成的标准答案；需要内容审核的裁决仍由对应角色执行。
- 部分错误优先整理到具体小问；错题本保留完整大题背景、学生原作答、参考解答来源、错因假设与避坑要点。
- 未作答可单独加入“待补做”，不增加已确认错误次数；识别失败可人工补录，不能被系统显示为已正确。

### 自动化程度

**首期默认：自动识别与保存候选，批量确认正式入库。** 这是最小操作的默认方案，仍沿用 R2 的可信确认要求。

后续可以对经过验收的题型启用“符合规则自动入库、其余复核”。启用必须由有权用户通过管理界面明确设置，绑定学习者、来源类型、题型、校验方式与策略版本；模型不能自设策略。只有转写/定位、答案映射与判定都满足已验证规则、且没有冲突或缺失条件时才自动提交，仍需可审计和可撤回。该模式是新增门槛，不表示首期已经开放。

不以模型输出的单一置信度阈值放行；阈值与覆盖范围须用独立标注样本评估，不能把“模型说 95%”当作实测准确率。

## 5. 数据模型：资料、题目、错题记录分别保存

以下均为独立 Learning Service 中的拟议实体，复用主规划的账号、作业任务、题目版本、诊断和复习卡，不写入 `webui.db`。

| 实体 | 主要字段与约束 |
| --- | --- |
| `source_documents`、`source_pages` | 学习者、资料类型、学科、可选原完成日期、上传时间、文件哈希、自有对象引用、来源 ID、页码、排序和质量状态；答案文件单独标记用途 |
| `import_batches`、`import_runs` | 批次/运行 ID、文件版本集合、状态、处理配置版本、取消/失败原因；使用已有 `jobs` 租约和重试机制 |
| `import_items`、`source_regions` | 稳定题目定位、父题/小问 ID、跨页区域、坐标系与旋转映射、题干、学生原作答、批改证据、修订号、分题/转写审核状态 |
| `answer_key_mappings` | 参考答案来源与访问范围、卷版本、题号/小问映射、评分规则版本、审核状态；不把教师改写当成学生原作答 |
| `import_judgments` | 项目版本、结果、判定来源、可核验依据、疑点、审核状态与规则/模型版本；历史判断保留，修订不覆盖 |
| `mistake_entries`、`mistake_sources` | 学习者、已确认题目版本、导入项目/原作答引用、来源区域、错误发生记录、确认方式/策略版本、诊断状态、归档/撤回状态 |

已核验原作答可形成 `attempts` 的导入观察记录，标记 `source=uploaded_work`、`assessment_eligibility=false`，缺失步骤与日期保留缺失。它与系统内已冻结题目的独立测验提交不是同一类证据。

错题本对同一来源题目保持唯一有效关联；一次导入修订应修正既有记录，不重复计算一次错误。相同知识点的不同题、同一道题在不同日期真实再错，应保留不同发生记录并汇总到同一复习目标。

### 去重与一致性

- 幂等键绑定账号、学习者、操作、导入批次和修订版本；同键同内容返回原结果，不同内容拒绝。
- 相同附件哈希只提示可能重复，不直接代表同一学习事件；同一学习者确认复用既有来源时返回已有结果，明确“另一次作业/作答”才建新来源。跨学习者不暴露重复命中。
- 换角度拍照、裁剪后重传与相似题用相似度提示人工关联，不因视觉或文字相近就删除真实的另一次错误。
- 一个批次允许部分成功，但每项的正式错题、来源关联、导入观察及建卡请求必须在短事务中一致提交；显示逐项结果与计数，失败项可重试。
- 模型/OCR、存储转换和等待确认在数据库事务外运行。确认只消费当前 revision；迟到 worker、已取消批次或旧确认不得生成有效记录。

## 6. 与归因、可视化和复习的衔接

- 正式入库后才异步生成有证据的错因假设；归因失败显示“待分析”，不撤销已保存的可信原题与错误来源。
- 新目标在知识点映射和目标确认后，按 R2 首次建卡规则安排复习；未映射项目显示“待关联考点”，不虚构知识点 ID。
- 已有目标仅关联新的错题来源并可提出诊断任务，不因为导入旧卷、识别到扣分或同卷重复上传就重置阶段、增加独立失败次数或晋阶。
- 外部试卷的完成日期与辅助情况通常不能由上传本身验证；保存其来源信息，但不把导入成绩直接作为调度证据，也不按历史日期自动补跑复习。
- Agent 根据实际错因选择对应的静态图、数轴/等式交互或分级提示；不能因为识别到错题就为全卷逐题生成昂贵动画。
- 导入复核中展示的参考答案、订正和解析沿用提示暴露规则；活动测验期间，相关题目/目标的答案资源由服务限制访问或先标记辅助。原卷自带批改答案也不是无提示测验材料。

## 7. 接口与权限边界

接口名为拟议内部 `/api/v1` 契约；按权限发布，不能整份注册为模型工具。

| 动作 | 允许的调用方 | 约束 |
| --- | --- | --- |
| 上传资料、调整页序、关联参考答案 | 已认证 UI；或可信适配器转交已授权附件 | 真实学习者上下文、文件所有权与大小/页数限制；接收上传字节或受管引用，不接收任意抓取 URL/磁盘路径 |
| `request_document_analysis` | 允许清单中的模型工具或 UI | 只能请求分析既有已授权资料；幂等建任务；返回 job ID，不返回伪造完成状态 |
| `get_import_status`、`list_import_candidates` | 已授权模型工具或 UI | 按学习者过滤；候选解析与答案受活动测验暴露门禁控制 |
| 修改分题/转写、申请批量确认挑战 | 已认证 UI；受信适配器可编排 | 绑定批次、题目、选中集合和版本；内容修改使旧挑战失效 |
| `confirm_import_batch` | **仅可信 UI/适配器回调** | 消费 R2 操作绑定的一次性挑战；模型不能提交 `confirmed=true` 或任意判对/判错结果 |
| 启用自动入库策略、争议裁决、撤回记录、资料删除 | 具备相应权限的管理 UI | 角色校验、版本条件与审计；学生身份不能被服务凭据代替 |

撤回入库保留修订轨迹；若首次建卡仅由该记录产生且尚无其他有效学习证据，可按规则撤销待复习来源。若已有后续有效尝试，不删除或覆盖它们。涉及历史成绩修订时沿用 R2 的补偿/重放门槛。

## 8. 上传处理与升级隔离

- 原件、页图、裁剪、转写版本和答案映射保存到学习服务自己的附件存储；WebUI 文件 ID 只作来源引用，删除聊天不应导致正式错题失去唯一原件。
- 文件类型按实际内容校验；配置单文件字节数、总页数、渲染分辨率/总像素、任务时间和并发上限。密码保护、损坏 PDF 与超限文件给出可恢复说明；不能静默截断。
- PDF 解析、图像处理与 OCR 在独立 worker 中运行；不执行文档内嵌脚本，不跟随任意外部链接。学科文本中的指令按资料处理，不具有工具执行权限。
- 需要外部 OCR/视觉模型时，按既有外发设置确认处理范围，优先发送必要题区；提供商、版本、超时和预算显式配置。本轮不指定未经样本验证的产品或调用付费接口。
- 附件接口与临时访问凭据继承学习者权限；参考答案与学生提交分离。保留、导出和删除覆盖原件及派生物，复用 R2 生命周期策略。
- 上传入口、原生附件权限及获取方式集中在薄适配器；学习业务不导入 `open_webui.*`，也不挂载 WebUI 内部数据目录。
- OCR/版面模型与提示词升级单独验收，历史识别结果保持冻结；重跑产生新版本，不静默改写正式错题。备份与恢复同时核对文件、页码区域、题目、答案映射和确认版本。

## 9. 实施顺序与验收

| 阶段 | 交付 | 前置/完成门槛 |
| --- | --- | --- |
| U0 样本与入口验证 | 清晰多题照片、已批改卷与对应答案样本；验证真实附件授权和原件获取 | 依赖 P0；明确各题型基线、参考裁决与外发设置，不把教材 RAG 导入成功视为试卷识别通过 |
| U1 上传与整理 | 多图/PDF、异步任务、质量提示、分题、原图定位、候选列表 | 依赖 P1 的身份/附件/作业机制；可补页、纠正分题、取消与恢复；漏页可见 |
| U2 判错与入库 | 批改识别、参考答案匹配、支持题型校验、可信批量确认、正式错题本 | 复用 P2 的校验与 P3 的交互；未知不误判，重复不多记，来源可追溯 |
| U3 复习闭环与回归 | 归因、建卡/关联、教学素材选择、独立复测、升级恢复验证 | 导入不重置已有阶段；测试通过后进入 P4 真实试用 |
| U4 扩展自动化 | 经批准的自动入库策略、复杂手写/几何、更多学科 | 用独立标注样本验证实际覆盖与误判；未达标范围保留复核 |

U0–U3 纳入完整产品试用前的必需范围，安排在基础身份与数据接口可用之后、批量扩展动画内容之前；U4 后置。原 R2 的 11~17 人日仅覆盖原基础闭环，本增补会增加分题、识别评估和复核 UI 工作量，不能沿用该数字作为含本模块的新总工期。先完成 U0，再合并 P1–P3 的共用工作重新估算，避免重复计费。

验收必须包含：

1. **识别与覆盖**：整页多题、小问、跨页、多栏、缺页、模糊/旋转、负号/分数/指数、教师与学生笔迹区分；正确项抽查及人工标注未识别区，分别报告漏题和错题漏检。
2. **判定**：正确/错误/部分错误/未作答/无法判定分流；红笔下划线不当叉，满分或对勾不当错，标准答案错版/选项重排/冲突强制复核。
3. **证据与身份**：原图位置可回查；两个学习者不能互查附件/任务/错题；伪造文件 ID、模型确认、过期挑战与确认后换版本均被拒绝。
4. **一致性**：同批重试、多端确认、重传图片、worker 重启/租约过期、取消后迟到结果、部分入库失败；来源和错题至多记录一次，历史不被新 OCR 覆盖。
5. **调度与泄露**：导入正确或错误均不冒充独立测验；已有阶段保持不变；新目标只建一次卡；查看答案有正确的暴露处理；撤回不误删后续学习证据。
6. **质量报告**：使用包含全部题目的人工标注样本，以文档/题目模板分开开发与验收集；分别报告分题完整率、关键符号正确率、判错精确率、错题召回率、待复核比例、各题型样本量、耗时和成本。不得排除失败页和弃判项后宣传“全卷准确率”。

达到验收门槛才能标记“已上线”。设计完成、处理演示样本和真实学生持续使用是三个不同里程碑。
