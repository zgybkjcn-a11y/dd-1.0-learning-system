# DD-1.0 人工参考集准备规范

日期：2026-11-04。状态：只有空模板；未收到真实资料、人工标注或审核结论，T04 仍 blocked。此目录不保存实际学生材料、标注记录、密钥或质量评估结果。

## 使用与资料范围

将模板复制到独立、受控、不会提交 Git 的资料目录，例如已忽略的 `learning_data/quality/<dataset-id>/`，先核对该路径确实被 Git 忽略。资料取得及本地使用需要明确授权；脱敏不自动授予外发许可。真实 API、真实学生资料外发和生产部署仍遵守当前会话限制。

`reference-dataset.template.json` 是空的数据集清单，CSV 是零记录的标注工作表，`acceptance-policy.template.json` 是尚未签核的验收口径。模板的空数组、null 和 pending 表示缺输入；不能将它们解释成零错误、准确率 100% 或审核通过。合成回归与脱敏参考资料不得混在同一验收结论中。

## 标注文件和字段

| 文件 | 每行表示什么 | 关键约束 |
| --- | --- | --- |
| `documents.template.csv` | 一份来源资料 | 文档 ID、原件 SHA-256、类型、总页数、课程与母题分组、开发/验收划分、允许使用范围 |
| `pages.template.csv` | 原件中的一页 | 文档 ID、从 1 开始的页序、原页宽高、方向/渲染变换、清晰度及失败原因；失败页不丢弃 |
| `questions.template.csv` | 一个主问题或小问 | 唯一题 ID、文档/题号、父题与母题组、题型、原始题面、学生作答、教师证据、答案版本、五类参考判定和审核人 |
| `regions.template.csv` | 某题在某页的一块区域 | 题 ID、文档/页序、区域类型、原页坐标；跨页/多个区域使用相同题 ID 的多行 |
| `reviewers.template.csv` | 一名审核人的脱敏标识 | 审核人 ID、角色/题型范围及复核状态；不填写不必要的姓名、手机号等身份信息 |

CSV 使用 UTF-8，包含逗号/换行的字段按标准 CSV 引号转义。ID 使用脱敏稳定标识，文件名不包含学生姓名。不得把模板文件名或占位文字当成真实原件和审核人。

## 原文、答案、判定与区域

1. `question_raw_text`、`student_raw_answer` 保留原文，不用模型纠正或补写。缺步骤/看不清明确标 unknown/illegible；已核实未作答使用 `student_answer_status=unanswered`，原答可为空。不能由空单元格推断未作答或错误。
2. `reference_verdict` 只接受 `correct`、`incorrect`、`partial`、`unanswered`、`undetermined`，分别表示正确、错误、部分错误、未作答、无法判定。unknown/尚未审核使用空字段和 pending 状态，不冒充 `undetermined` 已审核结论。
3. 教师标记属于证据，红色、叉号或模型置信度不是单独的充分判定依据。记录人工证据、参考答案文档 ID/版本、定义域和单位；错版或冲突显式标 conflict 并复核。
4. 坐标统一为 `original_page_pixels`：原页左上角为 (0,0)，x 向右、y 向下，满足 `0 <= x0 < x1 <= width`、`0 <= y0 < y1 <= height`。保留图像旋转/裁切到原页的变换；不能把规范化坐标、旋转后坐标与原页像素混用。
5. 区域类型可为 question、student_answer、teacher_evidence。跨页题使用多个区域，不重复计算成多个独立题；主问题与小问的计数规则在评估前冻结。

## 开发集、验收集与冻结

- 先固定支持的课程和题型，不默认承诺全学科、Office 扫描图/复杂排版/公式语义。
- 按文档和母题组拆分，关联题/跨页题/同母题变式不跨开发与验收集合。题目级随机拆分不能替代文档和母题隔离。
- 冻结前核对原件 hash、连续页序、题/区域引用、审核人引用、判定证据、题型覆盖和冲突状态。明确审核负责人、版本、签核时间和指标口径后，再填写 `acceptance_frozen_at`。
- 不用模型标注代替人工参考。未审核、缺字段或冲突资料保留在缺项清单中，不填写虚构审核时间/结论。

## 覆盖清单

以下每项由资料与人工审核填充：多页；主问题/小问；跨页；模糊/低清晰度；数学符号；学生/教师笔迹区分；红笔批注；正确；错误；部分错误；未作答；无法判定；答案版本冲突；定义域/单位；首批支持题型。未知覆盖保持 pending，缺少某类明确写未覆盖，不伪造覆盖数量。

## 验收指标与分母

`acceptance-policy.template.json` 中阈值和人工签核默认 null。阈值必须在查看冻结验收集结果前由审核人确定；数值未定时不能自动通过。范围和失败页必须随报告一起披露。

- 页覆盖：输入总页数、成功页、失败页、待处理页全部列出；失败页不得从分母静默移除。
- 分题：按冻结的主问题/小问与跨页规则匹配人工参考，报告匹配题、漏题、多题；区域匹配使用事先约定的原页坐标和 IoU 规则。
- 转写：报告原始文本与数学符号错误，规范化规则预先固定；不得用“规范化”掩盖符号、单位或作答差异。
- 判定：按五类参考判定报告混淆矩阵；列出 TP/FP/FN、精确率/召回率及相应分母。弃判/待复核另列，不拿人工复核后的判定当作模型自动判定正确。
- 质量与运行：披露样本/题型规模、未覆盖范围、失败原因、逐页/逐题耗时和可核实费用。分母为零或结果缺失时标不可计算，不能写零错误或 100%。

该规范只准备 T04 输入，不宣称 OCR、判错、诊断、变式或真实学习效果通过。取得实际资料后再进行字段/引用校验、人工签核与冻结评估；没有样本时不生成质量结果。
