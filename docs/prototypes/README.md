# 离线学习交互原型

## 打开方式

用浏览器直接打开同目录 `signed_numbers.html`。该文件自包含，支持本地文件方式，无须启动 Open WebUI 或安装运行依赖。

## 能体验什么

1. 对 `-3 - (-5)` 先预测终点。
2. 按需查看提示，再逐格或连续播放数轴移动。
3. 对照向左走得到 -8 的错误路径，解释与正确操作的区别。
4. 换一道变式，重新隐藏图解和提示。
5. 暂停、重播、拖动进度或开启“减少连续运动”。

共有六道示例。图形刻度随题目和屏幕调整，每格仍表示 1；手机隐藏部分中间数值标签，但起点、终点、错误路径终点和零点保留。

## 实际验证记录：2026-11-02

- 用本机 Chromium 无头浏览器打开本地 HTML。
- 计算检查：210 组整数参数；检查差、位移、错误对照和起终点；5 组超界/类型输入被拒绝。
- 交互检查：初始结果隐藏、错误预测、逐格移动、辅助标记、减少动态效果、错误路径对照、换题重置、正确预测、播放/暂停和六道示例。
- 布局检查：1280px 桌面与 390px 手机；手机所有六题的终点标注均在图形边界内。
- 视觉复核：查看桌面与手机截图；发现初版手机终点被截断后改为自适应数轴，再重新检查。
- 桌面浏览器检查未出现页面脚本错误或 HTTP 请求。代码本身没有数据保存或外部接口调用。

这些是针对原型的检查结果，不是全浏览器兼容、完整无障碍审计、真实学习效果或线上安全验收。

## 使用边界

- 页面不连接任何账号、教材库或学习服务，不保存个人信息或成绩；刷新后重置。
- 页面包含本地计算答案和供检查使用的 JS 方法，不能作为正式考试或可靠掌握度证据。
- 看过图解后答对属于当堂辅助练习；真实系统应在后续到期测验中单独验证。
- 本轮没有调用在线图片/文本模型，没有生成视频/GIF，也没有接入 Open WebUI。
- 正式版需要沿用主规划 R2 的身份、可信输入、服务端判分和数据隔离；视觉素材需要独立版本与审核。
