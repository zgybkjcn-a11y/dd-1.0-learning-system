# 全学科题型扩充

本批给二上数学以外的12册教材、90个章节和附录范围各增加2道任务，共180道；包含七上数学12道、其余上册126道、下册42道。与此前二上数学的图表、推理和分步作答升级一起，已接入的13册、7个学科都已纳入题型升级。目录范围有题不等于整章知识点已经穷尽。

在“家庭学习”选年级、学科、教材与章节，展开“自己挑一道题”可看到新增题名与题型。同档出题会优先轮换未做过的题型；基础识记题仍归基础档，不因增加输入格而自动升级难度。每题2至4项，填数或下拉判断，全部正确才算本题答对。漏填会提示补全，刷新可恢复本标签页的草稿。

| 学科 | 本批任务示例 | 检查重点 |
| --- | --- | --- |
| 数学 | 有理数位置、分段收费、去分母检验、双角平分线、平移逆推、频数频率 | 分步结果、条件约束、单位、检验 |
| 语文 | 原创短文阅读、词义和偏旁、故事排序、视角转换、修辞与论据辨析 | 信息提取、语言理解、表达依据 |
| 英语 | 交友卡、课表、通知、家庭关系、语法填空、词典排序 | 语境、时间条件、指代和语言形式 |
| 道德与法治 | 班级规则、隐私、自我认识、求助、诚信与责任 | 情境中的行动与理由辨认 |
| 历史 | 遗址材料、改革措施、交流线路、政权时序、年表 | 时空联系、史料限度、因果 |
| 地理 | 经纬度、比例尺、等高线、气温降水、人口、图例 | 空间关系、数据计算、限定结论 |
| 生物 | 实验变量、显微镜、细胞结构、动植物分类、食品保存 | 条件控制、结构功能、特征比较 |

题干、短文、表格与解析均为本地自编，依据已接入的固定教材核对主题，未导入商业题库。展示档位20题基础、152题正常、8题困难是试用分档，尚未按真实学生表现校准。453个作答项只算180题；同一能力的改数题或增加输入格不额外算新题型。

## 需要独立表达和操作的补充任务

以下可直接作为家庭练习任务单使用，独立记录孩子是否需要提示。每项按“完成／需提示／待练习”记录，暂不接自动分数，也不把选择正确当作实际表现已通过。二上与七上数学另有[二上任务单](math-g2-practical-tasks.md)与[七上任务单](math-g7-practical-tasks.md)。

| 范围 | 实际任务 | 核对要点 |
| --- | --- | --- |
| 二年级语文上下册阅读单元 | 选本单元一篇已读课文，用自己的话讲清起因、经过、结果，再指出支持理解的一句话 | 顺序清楚；不编造文本事实；能回到原文 |
| 二年级语文识字与词语 | 从本单元选4个形近字，各组词并写一个句子 | 字形、词义与语境匹配；书写另看笔顺与结构 |
| 二年级语文表达 | 写4至6句观察日记，标明时间，写两个观察细节，再读给家人听 | 句子通顺；观察和想象分清；标点合适 |
| 七年级语文上册 | 围绕一个人物或景物写一段150至200字的文字，加入两个具体细节；修改一处空泛评价 | 中心集中；细节支撑；修改有理由 |
| 七年级语文下册 | 选一个观点，写出两个独立事例及各自与观点的联系，再指出材料局限 | 论据相关；解释联系；避免绝对化 |
| 七年级语文古诗文 | 选本单元已学短段朗读，结合注释解释两个词，再说明一句的意思 | 读音与停顿；词义贴合语境；译述不遗漏关键关系 |
| 七年级英语问候、家庭、校园 | 两人轮流问答姓名、家庭关系和校园位置，至少交换6轮信息 | 听懂问题；信息对应；出现不懂时会请求重复 |
| 七年级英语科目、社团、作息、生日 | 根据两人的空闲时间商量一项活动，口头约定时间地点，再写一则40至60词通知 | 条件兼容；时间准确；句子可理解；信息完整 |
| 七年级英语听力与语音附录 | 家人读教材中已学短对话两遍，孩子不看文字记录时间、地点、人物，再复述；另朗读已学词组 | 听辨与纸面阅读分开；不要求模仿单一口音；看可理解性 |
| 二年级道德与法治 | 为班级或家庭共同事务提出一个建议，听取另一人的意见后调整 | 能说明理由；尊重不同意见；有具体行动 |
| 七年级道德与法治 | 围绕隐私、友谊或责任情境，提出两个可行办法并比较各自影响 | 考虑自己与他人；选择有理由；需要帮助时知道求助对象 |
| 七年级历史 | 用本单元5件已学史事制作时间轴；选择两件解释联系，标出材料来源 | 年代顺序；不把先后直接等同因果；事实与推测分开 |
| 七年级地理 | 画一张熟悉区域简图，含方向、图例、关键地点；用给定比例尺说明一段距离 | 方向与相对位置一致；图例可读；单位换算正确 |
| 七年级生物 | 设计一项比较幼苗生长条件的观察，不实际培养未知微生物；列出变量、控制条件、重复和记录表 | 一次只改变研究因素；有对照与重复；结论限于记录 |

每章还需按本教材具体课文、词汇、语法或知识点逐项对照课程标准与学习要求。审阅包中的“范围任务清单”记录本批实际检查的任务与人工环节，不据题量计算虚假的完整覆盖率。所有题目前均为助手核对，教师复核与实际教学效果另记。
