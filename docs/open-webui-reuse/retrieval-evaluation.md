# 检索与引用评测规程

A06 将旧 20 问保留为开发集、审计 4 问保留为回归集，另冻结 40 问试点集。真实问句、预期证据、教材文字和逐题结果只存本机忽略目录；公开源码包含[通用运行器](../../scripts/evaluate_textbook_retrieval.py)与[原创合成测试](../../tests/test_textbook_retrieval_evaluation.py)。首次冻结与结果见 [A06 验证报告](../verification/A06-retrieval-evaluation-2026-11-07.md)。

## 冻结与复核

每题保存案例 ID、表达组、curriculum/book/chapter 范围、问题、可接受与全部必需证据集合、预期结果、理由、复核者类型/方法/状态。试点固定为 20 个可回答、10 个同范围无依据、10 个范围负例；多证据问题另外统计全部必需证据覆盖。开发、回归、试点分别计数，不能合并分母。

`pilot-v1.json` 固定全文金标准、来源/复核身份及有效日期、top4 和阈值。`freeze.json` 固定三个分区、旧开发原件、材料清单、基线实现哈希和冻结时间；运行时必须显式提供 freeze 文件的 SHA256。基线 CLI 拒绝实现变化、材料缺失/失效或预期变化。目录版本名仅是标签，实际身份由哈希确定。

本版由同一执行助手逐项对照完整片段及排除范围，未依据 `retrieval_terms` 编题，执行基线前已冻结；作者已读算法和历史失败。表达组与开发/审计问题隔离，但共用五片段和概念，**不是独立人员、教师或外部盲测**。内容复核记录也不提供整页审核或题目判分资格。

问句、预期、阈值或材料有效身份变化必须建立新版本并保留旧版。看过结果用于调参时，先在 `exposure-log.json` 登记该集转为回归集，再另冻结未用于调参的表达组；不能以原题反复变绿宣称独立泛化通过。`defects.json` 保留失败题、观察结果、复核理由及修复状态。

## 指标与失败口径

| 指标 | 分子 / 分母 | 冻结目标 |
| --- | --- | --- |
| Recall@4 | 前四条中至少有一条预期有效片段的可回答题 / 20 | ≥18/20 |
| 无依据拒绝 | 成功处理且未返回片段/引文的无依据题 / 10 | ≥9/10 |
| 范围泄漏 | 返回片段/引文的范围负例 / 10 | 0/10；同时要求成功处理 10/10 |
| 来源准确率 | ID、源 PDF/版本、书章、双页码、复核版本均符合金标准且未失效的片段 / 全部返回条目 | 100%，分母不能为 0 |
| 完整引文一致率 | 本次检索中、与金标准全文相等且不重复的引文 / 全部引文 | 100%，分母不能为 0 |
| 引文完整交付率 | 上述有效引文 / 逐题 `max(返回条数, 引文条数)` 之和 | 100%，防止少报或省略引文 |
| 相关精确率 | 符合预期的有效片段 / 全部返回条目 | 补充报告；不等同于来源准确率 |
| 必需证据覆盖 | 命中的必需片段关联 / 全部必需关联；另报全部满足的题数 | 单独报告多证据题与逐概念表现 |

召回检查来源、全文、范围及前四条位置，不依赖候选自身的引用验证函数。引用错误另行记录并阻止整体验收。返回条目重复、伪造 ID、错版本、错页、错书章、文本篡改、超 top4、缺引文或自由生成答案均产生完整性错误；额外无关条目不能增加召回。逐题精确通过还要求证据集合符合预期。

异常保留原分母，不能算成功拒绝。只有目录授权检查返回已知拒绝码时，才能记为 `scope_rejected`；后续检索即使抛出同名异常也记为运行错误。日志只记录固定错误码，不打印异常原文。零泄漏同时要求十题成功处理，故全部超时不能“通过范围隔离”。

查询中换档案、超时等服务契约沿用 A04 对应版本的独立测试证据，不能从离线 40 问推断在线路径已验收。材料到期/撤回/换文/坏源由片段加载合成测试单独覆盖；它们不混入无依据题分母。

## 本机执行

从仓库根目录用锁定测试环境运行，材料及评测目录须已在忽略范围。输出目录必须是新路径，不能覆盖旧样本的 `evaluation.json` 或 `preview.html`。

```bash
python -m pytest -q tests/test_textbook_retrieval_evaluation.py tests/test_textbook_passage_sample.py
python -m scripts.evaluate_textbook_retrieval \
  --evaluation-dir learning_data/verification/a06-retrieval-evaluation-20261107T125008Z \
  --freeze-sha256 dec6d811720149f2344d52ac438f9ad711158ceddddd5f4d8bd672d63573f9df \
  --bundle learning_data/verification/textbook-passages-20261107 \
  --textbook-dir learning_data/textbooks/pep-current-20261105 \
  --output learning_data/verification/a06-retrieval-evaluation-20261107T125008Z/baseline-new-run
```

退出码 `0` 表示完成且试点质量目标通过，`2` 表示已完成但未达目标，`1` 表示输入无效/不可用或输出已存在。退出 2 仍写详细结果和文件哈希，不是运行失败。读取当前日期验证材料，无 `--as-of` 参数；到期后需重新复核并冻结新版本，不能用历史日期重获引用资格。

重复运行用两个新目录，对比 `partitions`、`criteria`、输入/代码哈希及日期；只有执行时间可以不同。每次结果记录三组各自指标、逐题观察、复核/独立性声明与运行器 SHA256。

A05 候选可调用纯函数 `evaluate(cases, gold, adapter, today=当前日期)` 和 `pilot_criteria(metrics)`；adapter 接收一题副本，返回 `status`、`retrieval`、`answer`。候选必须另记实现/材料/题集哈希和当前日期，不改写 A06 的基线 freeze。若改变协议，先用合成数据验证映射。运行器不加载任意插件、不调用真实模型，也不授予上线资格。

## 回退和交付

运行器没有接入服务或 Tool；停用它不会改变线上能力。发现评分错误时保留原结果，修正运行器、增加针对性测试，以新输出目录和新代码哈希重新评测；如题目/预期/阈值也变化，则同时升级题集版本。A02/A04 的封包保持历史原样，A06 的增量单独保存，禁止据旧清单整体暂存当前工作区。
