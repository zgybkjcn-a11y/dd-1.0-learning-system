# 二上数学提高练习与题型修正

针对“太简单、太单一”的实际反馈，补充48道自编提高题：8个单元/活动各6道，正常档2道、困难档4道，共16道正常、32道困难。21道带分类表、校园图、方阵或尺子示意图。题目需要读表比较、从结果倒推、逐项尝试、修正错误、处理重叠、比较买法和综合运算。输入仍为数值或编号；不声称已支持拖拽、手写解答或自动评阅推理过程。

家庭学习中选择“二年级上册数学”及章节，将“挑战难度”选为“正常”或“困难”，即可优先做本批题。也可打开“自己挑一道题”，按显示的题型挑选。自动进阶仍从简单开始，按既有独立作答规则升档。

例如，分类题要求从18张卡片、10张红片、11张圆片和6张红圆片中推断蓝方片；路线题要在校园图中避开操场找路线；测量题比较起始刻度不同的两条线段；表内乘除题通过尝试确定5个大小盒如何装下38个球；复习题比较不同包装的最省买法。

35道旧题原先把基础辨认或一步求值标为困难，现调整为5道简单、30道正常。旧题号、题干、答案、已提交作答和数据库原行保持；当前建议档位按修正分档重新计算。已经完成的旧档位记录继续保留，题目在修正档位进入新的练习轮次，不会因旧档位完成记录而无法重练。

出题时优先选择本轮较少出现的题型，在同等条件下先出本批提高题，并保留固定顺序，避免页面刷新时跳题。相同模板换数按一类处理。这个规则只改变二上数学的候选顺序，正在作答的题按原快照恢复。

数学运算尽量限定在已学的表内乘除和100以内加减；有些题适合用画图、连加、配对或试数解决，不要求提前学习方程。尺子图以标明刻度为准，不能直接量屏幕。校园图、表格和图示由本项目绘制，不使用外部图片生成服务。

48道题有唯一的数值/编号答案、提示和解析；自动判分核对最终结果，口述方法、实际测量、自由作图仍需孩子实际完成。覆盖表v4只追加对应或辅助映射，保留独立解释与实测缺口。二上76项能力中31项达到两种对应题型目标、35项部分配题、10项尚无映射；这仍是助手清单草案，无教师签署、未完成课程标准交叉复核，不能称为整章完整覆盖或真实难度校准。
