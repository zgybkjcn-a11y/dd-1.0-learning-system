# 七上第二章内容覆盖表

B01 的交付是独立离线覆盖数据和 HTML 核对表。源数据为 `learning_service/data/family_chapter_coverage_v1.json`，生成入口为 `scripts/prepare_chapter_coverage.py`。本批不改变运行服务、范围选择、旧概念库或题库；8 条新增映射只在覆盖候选中记录，尚未发布到知识参考接口。

19 行来自现有概念库、固定教材原件的目录/相关教学页与全章小结：13 行本章知识点、3 行先修回顾、1 行本地检查、2 行综合实践。它是本批明确盘点的范围，不证明教材中所有知识点均已穷尽。加法/减法、加法运算律、乘法、倒数、乘法运算律、分配律、多个乘数的积的符号、除法、乘方、混合运算、科学记数法、近似数分别列行。综合实践中的进位制转换和二进制加法也保留缺口。

表中“教材定位”仅指可回查的页码。原有先修定位保留第一章归属，未移动成第二章正文；“核对题意和单位”的教材定位继续留空。五个有效片段分别关联加法、减法、倒数、分配律、多个乘数的积的符号；同页的其他内容不因此获得有效片段覆盖。缺少本地讲解、练习或复习映射时字段为 `null` 或空数组，显示为“留空”。

12 道第二章应用题每档各 4 道。4 条映射沿用旧概念库的固定题版；8 条由助手依据现有题干、提示与解析核对，保存理由、来源指针及题目哈希，未新增题目或授予新的判分资格。每行题数可能重叠，本批共有 42 次题目与知识点关联，独立题量仍为 12。未映射题会继续计入全章分母并独立列出，不因缺映射而隐藏。

复习列指明确核对过的教材回顾题/资源定位，17 行有此来源；综合实践两行的复习资源仍留空。实际错题收藏、复习卡数量、到期情况和 1/3/7 天观察均为 `null`，没有读取学生或正式 WebUI 数据。这些结果不能替代 B02/B05 的内容、流程与实际观察验收。

生成命令使用当前北京时间，没有历史日期参数；需要本机授权教材和五片段包：

```bash
python -m scripts.prepare_chapter_coverage \
  --bundle learning_data/verification/textbook-passages-20261107 \
  --textbook-dir learning_data/textbooks/pep-current-20261105 \
  --output-dir learning_data/verification/NEW-INDEPENDENT-DIRECTORY
```

输出目录必须不存在。生成器先核对四份公开输入的固定哈希、教材 PDF 与原生页文本定位，再调用既有片段校验器检查图片、复核绑定、启停和当前日期。出表前再次检查输入与日期；失效片段不补写替代关系，坏材料拒绝出表。`coverage.json`、`coverage.html` 和 `manifest.json` 在独立目录中生成；清单记录输入与生成器哈希。教材原文、上下文和图片不写入覆盖报告，原生文本核对材料另留忽略目录。

HTML 无外部资源或运行服务请求，可直接用浏览器打开并展开题目 ID。报告显示核对日期，片段有效期截至 2026-12-07（含当天）；历史 HTML 是核对快照，再次使用必须重新生成。助手核对不等同于教师签署、整页审核、真实模型或家庭体验验收。
