# 主站课本聊天、教材检索与学科快捷提问

已注册并上线；[验证与发布记录](../verification/main-chat-study-2026-11-07.md)。

用户于 2026-11-07 明确要求执行“聊天中的只读学习 Tools＋原页引用”，并追加授权教材检索、学科助手与快捷提问接入；“检错”已由用户澄清为检索。这次只为当前家庭绑定的 WebUI 账号新增私有只读 Tool，不改其他工具、用户、模型配置、聊天、知识库或学习记录。

## 使用

主站聊天输入框旁“打开课本聊天”在新标签页打开原生新聊天，自动选择“课本伴学（只读）”。已有聊天草稿保留。首次先在家庭学习登录并选档案；不需要重绑或填写密钥。

- “学科助手”：在已有伴学面板选择学科、课本与章节（章节可选）。
- “查课本”：填入检索提问，用户补全关键词并发送后，由聊天模型按工具查询当前版本的教材原页。
- “分步讲解”“检查思路”“关联练习”：填入带年级、书章范围的提问草稿；不覆盖已有草稿，不自动发送。
- 直接在课本聊天中提出问题也可以使用工具；实际是否调用由所选模型及其工具调用能力决定。
- 回答的出处卡区分本地概念解释与原页检索位置，链接打开家庭页后点击查看对应原页；档案发生变化时要求重新查询。

工具每次从服务端核对当前档案。课本/章节的浏览器选择由快捷提问明确带入聊天；直接聊天没有指定书章时，先通过目录选择，数学默认当前年级上册。历史对话不会因为换档案而自动改写，换孩子学习应另开课本聊天。

## 六个方法

| 方法 | 内容 |
| --- | --- |
| `get_study_catalogue` | 当前档案可用学科、课本、章节 ID |
| `get_math_scope` | 当前数学书章的局部概念和关联题 |
| `get_math_concept_reference` | 已映射概念的解释、先修参考和原页 |
| `get_math_question_reference` | 已有题目的概念关联与练习链接 |
| `get_study_support` | 当前年级学科阅读问题串 |
| `search_textbook` | 当前书章关键词检索，最多四个原页位置 |

适配器为 `deploy/open-webui-reuse/readonly_study_tools.py`，独立于旧的十五方法业务适配器；正式只安装此六方法版本。没有写学习状态、诊断、批量导入、生成变式或提交答案的方法。

所有请求绑定 Open WebUI 注入的 `__user__` / `__request__`，先验证 Cookie 对应的 WebUI 身份，再使用既有家庭网关。只把白名单 Cookie 发给固定的两个本机服务；模型不能提供 URL、凭据、账号或学习者 ID。查询前后核对家庭上下文版本，不缓存个人会话。缺少登录、身份不符、档案切换、越界范围均不返回旧参考。

教材检索复用现有 `POST /learning/api/v1/textbooks/search` 只读检索功能，该 POST 不写题库或向量。测试使用合成检索响应，不调用真实 embedding/生成模型。工具只输出相关页标题、页码和链接，排除未核验的提取正文；数学解释来自已有哈希绑定的局部概念参考。引用事件使用原生 `citation` 格式，由宿主正常保存在用户聊天里，不含档案姓名、原始作答或会话凭据。

## 来源与边界

cn-math-taxonomy 贡献既有 29 道署名改编题（CC BY-NC 4.0），主站使用已建立映射的关联题；faststudy-knowledge 提供书章概念/先修/出处结构参考（代码 MIT、图谱 CC BY-NC-SA 4.0），本地人教版页码另行核对。仍只有 20题—18概念局部数学映射。其他学科提供阅读方法，不宣称已经有同等覆盖的学科图谱或已审核答案。

正式注册通过固定 ID、固定来源哈希的窄范围事务，只新增目标 Tool 和其原生历史快照，归属已有家庭绑定账号且不分享。既有同 ID 内容若不同则停止，不覆盖。注册脚本不加载正式 WebUI 配置/密钥，不读取其他 Tool 源码或聊天；不修改全局模型或默认工具。

本轮真实模型调用保持 0。原生加载和合成 API/浏览器验证不等于真实模型的工具调用质量或教学效果已经验收。
