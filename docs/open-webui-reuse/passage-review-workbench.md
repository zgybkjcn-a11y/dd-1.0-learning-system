# 片段复核工作台（B03 本地候选）

工作台为一个七上第二章原生 PDF 片段提供原页、转写、上下文和独立推导并排复核，另有问题处理、版本历史、启停与撤回。桌面三栏，手机按原页、转写、推导顺序排列，可单独放大原图。当前实际样本是书内40页 / PDF47页的倒数定义，仅核对该定义句及适用范围，不代表整页或全章审核。

这是独立维护工具，显式使用新的本地工作目录。服务只绑定 `127.0.0.1`，不导入家庭服务 app，不访问正式 WebUI 或学习库，不注册 Tool，不调用模型或 OCR。所有原图、转写、原生提取文字、审核日志与导出快照留在忽略目录。导入时先核对 A07 清单、来源 PDF、审核绑定和当前有效日期；原有审核仅作为历史来源，新工作目录仍从待核开始。

准备与打开工作台：

```bash
python -m scripts.passage_review_workbench prepare \
  --workspace learning_data/verification/NEW-B03-WORKSPACE \
  --bundle learning_data/verification/textbook-passages-20261107 \
  --manifest-sha256 d1bf256db814afcf35ff22f28ad32fd4577b4608e12f9d069b7f72cfc8cacd63 \
  --textbook-dir learning_data/textbooks/pep-current-20261105 \
  --passage-id g7-ch2-reciprocal-definition

python -m scripts.passage_review_workbench serve \
  --workspace learning_data/verification/NEW-B03-WORKSPACE \
  --reviewer-type assistant --reviewer-label '实际执行者说明' --port 8765
```

浏览器访问 `http://127.0.0.1:8765/`。已有目录拒绝覆盖，也不能在原始片段包或教材目录内创建工作目录。CLI 必须显式声明操作者类型和名称；`assistant` 是助手，`human` 是人工操作者的自述，二者都不能冒充教师签署。身份写入每条审核/操作记录，网页请求不能替换它。本批实际操作者为助手。回环 Host、同源检查与会话令牌用于防止其他网页调用；这是本机维护会话，不是可发布的多用户身份认证服务。

操作顺序：

1. 对照完整原图核对选取范围。原生提取文字只供比对，字体抽取或图片显示成功均不授予审核资格。
2. 纠正转写、调整上下文或来源 PDF 页码时，填写修改原因并保存新修订。来源只允许固定的七上第二章；教材本身有误时保留原文并登记问题。
3. 分别记录逐字/数字/符号、范围/完整性、版面/分式/行列的具体对照依据。仅勾选、空内容或泛称“已看”不构成记录。
4. 另填独立推导、条件、单位、图形依赖及完整等式。每个算式说明它与片段的关系；复用 `textbook_quality.check_arithmetic_claim` 做精确有理数检查，拒绝错式、除零、分列拼接和代码。原文是可识别的错误完整等式时不能以另一个正确等式掩盖。一般定义或规则仍由记录中的推导支持，有限算例不会自动证明一般论断。图形依赖未明确排除时，本批保持待核。
5. 未解决问题必须逐项记录处理依据；解决问题后仍需重新做两步复核。具备当前版本的两种依据、问题清零且有效期内，才能启用本地候选和导出历史快照。

内容修订号与审核记录序号分别计数。文字、上下文或原页修订都会增加内容版本，清空本版本的两种审核，并停用旧证据。新增问题、解决问题和撤回也要求重审；停用保留审核，可在内容和依据未变时恢复本地使用，但生成新证据 ID。撤回后必须建立新修订。所有写入在 SQLite 事务中比较 `expected_seq`，并发审核只有一次成功；冲突返回409，浏览器保留未提交表单，刷新前提示避免误覆盖。

完整日志以追加快照保存，包含前序哈希、动作、操作者、时间、原因、内容与双步骤依据。哈希用于发现意外修改，不是外部签名或防止本机管理员重写日志的证明。每次读取、展示原图、启用、引用和导出均重新检查来源 PDF、素材、配置与日志绑定；原页图片还绑定当前序号，加载后再次核对状态。来源损坏时停止展示和引用，在日志可用的前提下仍可停用或撤回。导出前如有未保存的文字/来源修改，界面要求保存并重审。

来源有效期继承 A07，本批至 **2026-12-07（北京时间，含当天）**；使用当前服务器日期，不接受客户端日期、延期或来源哈希参数。日期超出有效范围时，本地证据接口拒绝引用。重新审核不自行延长原来源有效期。持续打开的页面在下一次刷新/操作时核对状态，已打开的图片和历史截图不能追溯收回。

“启用”仅指当前复核工作目录，证据 ID 前缀为 `dd-review-`。导出是 `dd-passage-review-snapshot-v1` 的审核历史包，含完整日志、原图和哈希清单，不是 A07 的 `passages.json`，不能直接给主站加载。历史快照不会随停用而改写；当前有效性必须查工作台的当前证据接口。A07 原包、运行服务、Tool 和发布配置保持原样；未来接入运行清单必须另做版本适配、固定 pin 和发布验收。

所有结果保持 `teacher_reviewed=false`、`fully_reviewed_page=false`、`eligible_as_grading_basis=false`。当前范围不支持二下 OCR 完整页、图形复核或教师签署，这些不能借用本次片段通过结论。B04 应逐页按实际内容记录通过或待解，不能扩大自动通过范围。

本批提供独立维护源码包与定向测试，详情见 [B03 验证记录](../verification/B03-passage-review-2026-11-08.md)：

```bash
python -m pytest -q tests/test_passage_review.py tests/test_textbook_quality.py --fail-on-skip
python -m pytest -q -m browser tests/test_passage_review_browser.py --fail-on-skip
```

回退时停止本地工作台进程并恢复相容的维护源码，保留整个工作目录、素材、审核日志与已导出快照；不删除日志或覆盖旧候选。当前任务没有部署步骤，不需要变更生产服务或现有家庭数据。工作目录与审核快照都在本机，尚未形成独立故障域备份。
