# 七上第二章备用练习候选

B02 在固定的 60 道应用题库之外，新增版本 `2026-11-08-b02-v1` 的 12 道备用题，每档 4 道。旧题库和旧概念精确映射保持原字节。9 道新编计算任务、2 道新编情境、1 道同母题改数；每题保留来源、条件、单位、提示、解析、独立核算和 B01 覆盖行引用。分配律题只校验最终数值，不能证明学生实际采用了该方法。

`family-reserve-g7-two-rises-v1` 是旧题 `family-word-g7-storage-compare-v1` 的数值变式，保留母题哈希和变化说明。家庭界面显示“同母题改数”，数据库使用 `variant_kind=variant` 和固定题族，不计作新情境。其余题目由助手独立编写；全部经过助手语义核对和精确数学复算，`teacher_reviewed=false`，难度仍为试用分档。覆盖引用仅在本批审核包中记录，不自动发布为旧知识参考接口的精确映射；缺少教材片段或讲解的关系继续留空。

题版冻结采用题库字节、单题规范化内容和入库字段三组哈希。创建/恢复会话、提示、提交及判分前验证已安装内容、答案、校验器、题族、归属和课程；漂移拒绝继续，不改写旧题版。已产生的历史判分记录保持原样，取消入口仍可使用。

默认普通练习保持原选择规则。只有显式安装备用批次后，家庭七上第二章才显示“未见过的备用题”；其他年级和章节不添加此题组。首次会话创建已返回题面，因此取消、刷新或切换范围均不恢复“未见”资格。服务端按当前学习者与固定题版查 `test_items`，同题并发领取只允许一次；浏览器剩余计数立即减少，耗尽后不提供“再练一轮”。已有的匹配复习卡可按原到期、归属和并发规则再次练习，重复不会重新算作首次见题。

导入是显式调用 `learning_service.reserve_practice.install(db)` 的追加事务，调用方必须选择授权数据库；模块导入、服务启动和离线封包均不自动安装。本批只在合成临时数据库验证，未操作运行家庭数据。源码封包 profile 为 `reuse-runtime-practice-reserve-v1`，保留此前 A07 及更早 profile 的校验分支；旧包是历史源码集合，不根据新白名单补文件。本批不构建或部署镜像。

离线审核和冻结包不访问数据库：

```bash
python -m scripts.prepare_reserve_practice --output-dir learning_data/verification/NEW-INDEPENDENT-DIRECTORY
```

输出目录必须不存在。输出 `questions.json`、`review.json`、`observation-plan.json`、离线 `preview.html` 和哈希清单。审核页供成人审阅，答案在可展开区域；家庭发题接口不包含答案或解析。输入为公开备用题库、旧题库与 B01 覆盖候选，不读取教材正文或学生数据。

真实延迟观察尚未开始：基线作答 ID、基线时间以及 1/3/7 天到期、观察时间、结果均为 `null`。实际发生首轮作答后，记录同一题版、真实时区日期、是否用提示、是否见过母题、实际答题与家长反馈，再按安排记录每次观察。`windows(actual_started_at)` 只计算建议时间，不写入观察结果；缺席或未做的观察继续留空。自动化测试和“四题升档”均不证明掌握。B02 工程候选就绪与真实观察完成分别登记，后者待办时可继续 B03；A09 发布和家庭设备验收另列。

回退当前未部署候选只需恢复相容的源码入口；保留本批与 B01 证据。未来若已安装备用题，不删除曝光/作答/复习历史来恢复“未见”计数，也不把新库交给缺少备用题支持的旧源码。先停用备用题入口，使用仍能读取相应历史的相容源码与备份方案，另行验证；本批未实施生产回退。
