# 伴学读取作用域调度

在[只读连接复用](study-read-latency.md)基础上，`share_study_reads()` 进入原读取作用域前取得进程内可重入锁，结束后释放。原作用域的连接创建、autocommit、query_only、authorizer、身份与材料前后检查保持原顺序；每个作用域仍创建和关闭自己的连接，没有跨请求连接或授权缓存。

等待锁时每次最多等待 50 ms，并检查当前操作的取消状态及剩余截止时间；取得锁后再次检查。没有当前操作截止时，锁等待设本地 12 秒上限，该上限不代表整个无截止调用被强制终止。已有操作的 12 秒总预算保持，排队计入原剩余预算。连接建立失败、读取异常、取消或 BaseException 都释放锁；同线程嵌套可重入。

原普通写操作不取得此锁，其他连接提交撤权、切档或更新后，后置 SELECT 仍可见并拒绝旧结果。锁作用于本进程内所有伴学读取作用域，包含同进程的不同数据库，可能形成队首阻塞；不承诺 FIFO、公平性或任意规模吞吐量。它不跨进程协调，也不替代数据库事务或权限校验。同步 I/O 和原生渲染仍按原协作取消约定执行。

本地线程诊断先冻结对照与变体，串行作用域变体达到预设选择条件，再通过 194 项定向正确性验证及一次未改动的 900 请求原矩阵；12 项原 P95 门槛全部通过。独立记录见[调度与原矩阵验收](../verification/B10-thread-scheduling-2026-11-08.md)。此前缩短 Python 线程切换间隔、异步依赖、只读连接初始化和 GET 围栏变体均未采用，解释器全局设置保持原样。

新源码 profile 为 `reuse-runtime-study-read-scheduling-v1`，98 文件、schema13、Tool1.2.1、OpenAPI76路径/44模型。旧 97 文件 `reuse-runtime-study-read-connections-v1` 包保留为回退，不需要数据库降级。本地合成验收不替代正式部署、HTTP 生产负载或家庭设备验收。
