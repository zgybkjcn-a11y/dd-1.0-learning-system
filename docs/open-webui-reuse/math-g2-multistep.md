# 二上数学分步填空与多项判断

本批16道自编题覆盖二上8个单元和活动，每个范围2题，共8道正常、8道困难。每题有2至4个作答项，合计48项，其中8题带表格、校园图、方阵或刻度尺图。一道分步题仍按一道题计数，不能把48个作答项说成48道新题。

在家庭学习选择二年级上册数学及章节，将难度设为“正常”或“困难”，可优先遇到本批题；“自己挑一道题”中显示“分步填空”或“多项判断”。数值项逐格填写，判断项从下拉选项中选择。按回车可移到下一格，最后一格回车提交。漏填时会先提示补全。

系统逐项核对结果，全部正确才记为本题答对；部分正确会显示正确项数和需要重看的项目，本题仍按错答处理，不能推动独立答对进阶。系统检查规定的数值和判断，不自动评阅自由书写的解法，也不将选择正确解释当作独立口述、作图或实测。

未提交内容随既有机制保留在当前标签页，刷新、读取提示后可恢复；其他设备只能恢复已提交结果。重复提交沿用既有幂等机制，冲突作答保留为待核对内容。错题收藏保留字段标签与当时作答，避免只显示难懂的原始编码。

例如：

- “变了颜色也变了形状”：分别求变化后的红色、蓝色、圆形和方形数量，并在解析中核对两种分类的总数。
- “逐条检查绕开操场的路线”：对三条路线分别判断，不只猜一条正确路线。
- “彩带够不够再剪四段”：填写已用、剩余和还差的长度。
- “两种手串分步做”：依次填写用掉珠子、剩余珠子、后来条数及总条数。
- “核对两种整盒购买方案”：分别计算两种花费，选出便宜方案并填写差价。

相同数学结构沿用已有题型标识，例如非零起点测量、减去一部分再平均分、相同总量换分法和比较包装价格，不因增加输入格而重复计算新题型。覆盖表v5保留v4既有行和映射；11题计直接对应、5题计辅助。二上76项能力中35项达到两种对应题型目标、33项部分、8项空白，口述、实际测量和自由作图仍有缺口。清单、难度为助手编排，课程标准交叉复核、教师签署与学生数据校准待完成。
