## 五片段候选

[textbook_passage_retrieval.py](../../scripts/textbook_passage_retrieval.py) 接受原加载器验证过的有效片段，以及服务端可信的概念映射。试点仅配置加法、减法、倒数、分配律和乘积符号五个概念；映射不从问题、索引原文或模型参数读取。材料路径、身份、复核日期仍由原加载器验证。

流程为：当前年级/书章授权 → 全部有效片段按书章过滤 → 稳定证据身份去重、冲突拒绝 → 识别所查规则/定义与受限算式结构 → 检查请求是否超出片段能力 → 排名与 top4 → 全部所需规则覆盖检查 → 返回完整原文。输出没有生成答案或计算结果。

算式解析只查看加减乘除的语法树与分配结构，不执行表达式，不求值，不将命中视为数学证明。明确要求证明、推导、其他运算法则、图示、历史、跨领域条件或标准解答时，即使出现已知概念词，也不返回可引用片段。未知表达保持低相关；需要多条规则但不能同时满足时不拼接部分依据。

排序依据规则/定义意图和算式结构，分数只用于候选排序，不是概率或教学正确率。`items` 保留相关性顺序，`retrieval.ranking` 记录顺序和分数，`retrieval.display_order` 单独给出按页码排列的身份。先选择前四条再排列展示，不能按页码提前截断相关结果。

当前规则支持范围有意受限。仍可能误判未评测的表达、隐含意图或混合请求；不能据两组小样本全通过推断全书、任意回答或真实模型可靠。若扩展概念、表达或任务类型，应先复核材料和冻结新评测。

## 覆盖与失败契约

| 状态 | 适用情形 | 行为 |
| --- | --- | --- |
| `reviewed_excerpts_only` | 有界库中的规则匹配且所需依据齐全 | 可返回完整片段，`can_answer_from_textbook=false` |
| `no_evidence` | 当前有效片段范围为空，或所需任务没有片段支持 | 明确仅限本次已核对片段，不声称整本教材没有内容 |
| `low_relevance` | 不能可靠识别所查规则/定义 | 请明确概念或打开原页，不把弱词项命中当支持 |
| `insufficient_evidence` | 识别出的规则未全部在返回范围内得到覆盖 | 不提供片面的组合依据 |
| `incomplete` | 旧整册 top40 后过滤，或旧服务没有覆盖信息 | 即使返回为空也不能断言无依据；建议清空关键词按页阅读 |
| 上游/材料失败 | 超时、异常、材料缺失/到期/变更 | 保留独立失败，不吞掉为 no_evidence；沿用 A04 错误分类 |

五片段结果的 `coverage_complete=true` **只指已加载、有效、经过范围过滤的有限片段库**；`coverage_scope=loaded_reviewed_excerpts_only`。旧检索结果的 schema 为 `dd-retrieval-coverage-v1`，method 为 `collection_top_k_then_scope_filter`，coverage_complete 固定 false；返回不足 40 条也不能证明完整检索。上下游数量异常会拒绝，未经校准的向量距离不会伪装成可靠的相关性阈值。

旧路径保留按页去重和最多四个候选原页。每页 `retrieval_rank` 是它在上游结果中的原排名，顶层 `ranking` 保留筛选后的相关顺序；`items` 仍按页码展示以兼容原阅读界面。所有来源身份、册/章、版本和页码继续在返回前校验。

网关在向量请求前完成身份与范围校验，请求结束后再次读取当前学习会话。身份、档案或 revision 变化即丢弃旧结果；复核失败也不返回旧页。Tool 原有请求前后校验继续保留。Tool 1.1.2 投影安全的 incomplete 字段；旧服务未给覆盖信息时也明确 unknown/incomplete，不提升为完成检索。Tool 仍只返回原页位置，不能转述未经审核的索引正文。

阅读页有结果和无结果都显示覆盖不足提示，允许清空关键词恢复按页阅读。页面不暴露 top40、索引或内部错误等实现细节；空结果计数也不再显示 `1 / 0`。
