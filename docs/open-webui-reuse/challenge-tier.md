# 挑战难度与综合题

进入家庭学习，选择档案、学科、教材和章节，将“挑战难度”设为“挑战”，再开始答题。答题页的“下一题难度”也可以切换。四档依次为简单、正常、困难、挑战。

本批新增98题，13册教材的98个章节或附录范围各有一道。二上数学包含租车方案、重新分配、非零起点测量和预算筛选；七年级数学包含分类讨论、参数消项、计费边界与统计分组。语文、英语增加材料证据、词形纠错、对话或事件排序；史地生及道德与法治增加资料比较、条件筛选、检索分类和实验设计。

- 多选：勾选所有符合条件的选项，漏选或多选会提示重看。
- 排序：用“上移／下移”调整卡片，再核对顺序；如认可当前顺序，可点“确认当前顺序”。初始顺序不会自动视为已作答。
- 组合题：同一道题可以包含多选、排序、单选、数值和限定词语短答，每一项都正确才记为答对。

未提交草稿在当前标签页刷新后可恢复；已提交作答随会话保存。错答收藏会显示选项文字和排序箭头。提示后作答保留“辅助练习”标记。

自动进阶仍要求同一难度连续独立答对4道不同题。达到困难档后可以进阶挑战；错答或使用提示会降低一档巩固。同一题反复答对不会累计升级证据。

“挑战”是助手按多条件整合、逆向推理和证据检验设计的试用分档，尚未经学生表现校准。每个目录范围有题不代表知识点已穷尽；自由写作、口述、真实听说和实验操作仍需人工核对。
