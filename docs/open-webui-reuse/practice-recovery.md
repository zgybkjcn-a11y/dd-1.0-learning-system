# 家庭练习跨设备与轮次恢复

B06 本地工程已验收，候选未提交、部署。92项不同单元/契约用例及8项浏览器用例通过；仅合成身份、临时数据库与模拟视口。

## 恢复规则

- 学习档案拥有一份服务端工作区：课本、章节、普通/备用题、手动或自动档位、当前会话和递增版本。刷新、新标签、另一已登录设备读取同一状态；切档后各自恢复，不把浏览器完成列表当作依据。
- 轮次按“档案、课本、章节、题池、实际难度”隔离。完成列表只由关联本轮的已判分题项推导；主动“再练一轮”只重置所选范围当前档位的轮次代数，历史作答、其他档位、自动推荐和备用题已见记录不清除。
- 自动推荐仍由历史服务端判分、独立作答与不同题证据计算；手动档位跨设备保存，重练不会伪造推荐升级。收藏到期复习沿用原卡片调度，不计入普通练习轮次。
- 配置、开题和重练提交预期版本。并发冲突返回409，先读取最新工作区再由用户决定；不以过期页面覆盖新进度。当前题判分中禁止换题或换范围；未提交题须明确跳过后才能替换。
- 同题项同原始答案重试返回已保存作答，不产生第二份判分；不同原始答案返回冲突，页面保留后提交的内容供核对。未提交草稿仅在本标签页保存，提交成功后才能跨设备恢复。切档和退出前须处理未提交内容。
- schema13只新增两张表和题项关联字段，不改写旧会话/作答。旧客户端仍可使用既有接口和会话ID；没有服务端轮次关联的旧记录不追认成新轮已完成题目。

## 接口与迁移

`GET /api/v1/practice-workspace`只读，返回当前状态、版本和本范围完成题版列表；未初始化为版本0。`PUT`要求预期版本及范围/档位/题池，可明确跳过当前题或开始所选档位新轮。`POST /api/v1/test-sessions`可选工作区版本；省略时保留旧接口路径。

工作区写入字段为 `expected_revision/book_id/chapter_id/difficulty/pool`，`restart_round/discard_current`严格布尔且默认false；拒绝客户端完成列表等额外字段。新版开题传 `workspace_revision`，替换未提交题还需 `replace_current=true`。版本检查与开题、取消或新轮更新均在同一SQLite写事务中完成，既有档案切换写屏障继续生效。

旧客户端另开的测验可正常作答，但不自动加入新轮。新版不会从旧浏览器完成列表或多个旧会话中推测当前轮；旧会话继续按原会话ID读取。每个档案只有一份当前会话入口，切换范围保留各范围的完成记录，清空当前会话入口。尚未提交的浏览器草稿不是跨设备同步数据。

新客户端提交前保存本次原始答案、挑战与幂等键；响应丢失可用相同数据重试。服务端同题只保留一份正式作答，不把不同答案包装成成功。恢复页显示已保存答案和辅助标记，不向未作答题面泄露答案键。

迁移仅在独立临时库演练。回退应用时保留schema13的新增表/字段及完整学习库，旧代码忽略新增状态；禁止删除迁移记录或回滚已保存作答。正式切换、备份与家庭设备验收另行记录。
