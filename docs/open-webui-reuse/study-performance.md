# 伴学性能、材料缓存与请求总截止

B10 本地候选。性能样本、失败过程和验收结论见[独立记录](../verification/B10-study-performance-2026-11-08.md)。只使用原创合成材料、临时学习库和本地接口，不代表家庭设备或线上时延。

## 缓存与失效

原页和片段加载共用进程内 PDF 校验缓存（最多 4 项、32 MiB）；原页 PNG 缓存最多 32 项、32 MiB。超大单项照常校验/处理，不放入缓存。缓存没有磁盘持久化，也不保存账号、学习者、聊天或作答。缓存键包含绝对路径、设备/inode、大小、mtime_ns、ctime_ns、预期 SHA256；PNG 另绑定页号与渲染倍率。

每次读取仍检查路径及全部祖先没有符号链接、文件为普通文件、当前文件身份与服务端 pin。未命中时用禁止跟随符号链接的文件描述符读取，读前/后核对身份和 SHA256；命中时复查元数据。文件删除、替换、同大小改写并恢复 mtime、pin 改变均不能使用旧内容。渲染后再查源身份和 pin；同页并发未命中只渲染一次。原生 PyMuPDF 操作保留线程安全锁，命中直接返回已有 PNG。不同页的实际渲染仍串行。

这一机制要求本地文件系统提供一致的纳秒元数据。具有特权的 ctime 篡改和元数据不一致的网络文件系统不在已验收范围；遇到此类存储应使用逐次内容校验，不能把本机结果推广到该环境。旧版本键可能留在有界缓存中直到淘汰，但不会再被当前文件身份命中。

片段 manifest、启停/撤回、review、图像、语义依据和当前日期仍逐次校验，检索前后取当前快照。没有缓存“可引用”状态。原页也使用读取前后的档案版本与访问权限复核；网关在返回图像前再次核对身份和档案。所有公开响应继续 `Cache-Control: no-store`。

## 总截止与取消

Tool 1.2.1 每次公开方法调用共用 **12 秒**单调时钟预算，包含线程排队、身份、会话、资料、片段逐条及集合复核、最后档案复核和引用回调。网关与学习服务的伴学读请求也以 12 秒为上限。`X-DD-Study-Budget-Ms` 只允许缩短预算，重复/非法值拒绝，零值立即超时；网关不会把它转发给 WebUI 的身份/检索接口。服务间发送的是剩余毫秒，父请求仍保有自己的截止计时，不能靠逐层重新计时延长整个操作。

网关保留身份调用既有 3 秒单跳上限；其余伴学调用使用总预算剩余值。原先允许 30 秒的单跳不再延长伴学操作。非伴学写接口不纳入这次改动，不自动重试写操作。所有伴学请求也没有自动重试；用户重新操作会创建新的预算，超时不能解释为教材没有内容。

已连接的 HTTP socket 在截止或取消时 shutdown，响应头/正文缓慢逐字节到达也不能刷新总计时。浏览器断开与 Tool 协程取消会停止后续请求、丢弃迟到结果；同步材料操作在锁等待后、校验和读取出口检查截止。底层正在执行的 DNS/connect、文件系统调用或原生渲染不能由 Python 安全强杀，可能在调用退出前仍占用工作线程；已超时结果不能继续返回或触发后续读取。这是协作取消的明确边界，不声称所有操作系统工作在同一纳秒停止。

Tool 是独立单文件交付，内嵌的总预算辅助源码与服务模块逐字比较，公开六方法及模型可见参数保持。完整当前运行候选需携带缓存、截止、取消中间件三个新模块；不能单独替换 app.py。旧 B09 的 91 文件 profile 和归档保留原样，可单独校验和回退。没有数据库迁移，schema 仍为 13。

## 可复测基准

使用 A03 锁定 Python 环境，在新的 `learning_data/verification/` 子目录运行 `tests/benchmark_study_performance.py`；以环境变量 `DD_B10_OUTPUT` 指定不存在的输出目录。基准自身先写硬件/材料/矩阵清单，保留 PDF 和片段夹具、每条结果及 P50/P95。

固定合成 PDF 约 8 MiB，5 条合成片段；网关原页、片段检索及完整 Tool 检索各测并发 1/4、冷/暖，共 12 配置。每配置 30 波，单请求配置 30 样本、四并发配置 120 样本，合计 900。冷是每波清空应用缓存，暖是一波预热后重复同一页/查询；没有清除 OS 文件缓存。计时从各工作线程同时释放到响应/引用全部完成，包含排队与身份复核；P50/P95 用 nearest-rank，失败保留在分母。

ASGI 合成桥接没有真实网络时延；超时/慢响应另用 loopback socket 和受控延迟测试。性能阈值及 12 秒预算在测得旧实现基线后、运行代码改动前冻结；不靠放宽身份/证据检查达标。
