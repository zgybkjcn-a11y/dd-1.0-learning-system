# 二上数学：口述、画图与实测任务单

这份任务单补充线上选择题无法检验的动作。按需选一项做，先让孩子独立完成，再请家长按观察要点记录“独立完成 / 提示后完成 / 还需练习”。记录留在纸上，不自动写入成绩或把整章标为掌握。

## 1. 同一批卡片，两种整理方法

准备8张卡片：红圆3张、红方1张、蓝圆2张、蓝方2张。先按颜色整理并记录各类数量，再按形状整理并记录。请孩子说清两次的分类标准，并解释为什么各类数量不同、总数仍相同。

观察要点：每次使用一个明确标准；不漏卡、不重复计数；颜色为红4、蓝4，形状为圆5、方3；两次总数都是8。可以画表格或画圈记录，不要求固定排版。

## 2. 把同一幅摆法说成乘法和除法

用18个小物件摆成3组，每组6个。请孩子画出自己的分组，说出一个乘法和两个除法算式，并解释算式中的3、6、18各表示什么。然后改成6组，每组3个，比较两次摆法。

观察要点：18个物件全部使用，各组相等；能联系6×3=18、18÷3=6、18÷6=3；能区分每份数、份数与总数。乘数交换顺序可接受，不把一种书写顺序当作唯一正确表达。

## 3. 自己设计一条参观路线

在纸上标北箭头：校门在下方；花坛在校门正北；阅览室在花坛正东；体育馆在校门正东、阅览室正南。画出这些位置，设计一条从校门到阅览室的路线，口头带家长走一遍；再设计另一条路线。

观察要点：两条可行路线分别经过花坛或体育馆；说清起点、每段方向、转弯位置和终点。若画图采用其他方向朝向，要保持北箭头与相对位置一致。家长转身不应改变建筑物之间的固定方位。

## 4. 画一条线段，再验证

先用尺子画一条4厘米长的线段，标出两端。请孩子说明为什么它长4厘米，再换一个尺子起始刻度测量一次，例如把左端对齐2厘米刻度，检查右端是否在6厘米刻度。

观察要点：用直尺画直，两个端点清楚；测量时尺子沿线段摆正；知道长度取两端刻度之差。纸上实际画出的长度必须测量，不能仅凭口头报“4厘米”算完成。

## 5. 先估后量，保留两个结果

选择橡皮、铅笔和书的长边。先用熟悉的1厘米或一拃作为参照，记录估计长度；再用尺子实测，记录单位。比较每个物品的估计与实测差多少，解释下一次怎样改进估计。

观察要点：估计在实测前完成，不在量完后修改；两个结果都带单位；能比较差距、说明使用的参照。物品不同，正确实测值不固定，不使用统一数值答案。

## 6. 同一张桌子，不同的身体尺

孩子与家长先分别量自己一拃大约几厘米，再各自用拃估量同一条桌边。记录用了几拃及不足一拃的部分，估计厘米数；最后用标准尺核对。讨论为什么两人的拃数可能不同。

观察要点：每个人都使用自己的校准长度；连续量时尽量不留缝、不重叠；不足一拃的部分单独处理；不因为拃数少就说同一桌边更短。身体尺通常用于估量，结果与标准尺有差异时应解释原因。

## 7. 画一张能讲明白的知识图

让孩子把“分类、乘法、除法、方向、厘米和米、身体尺”整理在一张纸上，自选两处联系，用自己的话和例子讲给家长听。例如乘除法中的总量关系，或标准长度单位与身体尺的联系。

观察要点：允许多种合理组织方式；连接线上有能说明的关系；单位不混淆；例子与关系相符。家长提供的提示另记，不把照读给定解释当作独立表达。
