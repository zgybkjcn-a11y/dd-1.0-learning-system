# 主站伴学兼容与设备验证

固定兼容组合为 Open WebUI 0.12.5、家庭服务 schema13、只读 Tool1.2.1。主站资产通过既有 loader/custom.css 入口加载；家庭页只加载 family-bridge。版本升级后必须重新验证对应契约，不把本版本结果外推为任意上游版本兼容。

| 接入点 | 有效条件 | 失效行为 |
| --- | --- | --- |
| 聊天编辑器 | 唯一的 `#chat-input`，可见且可编辑的 DIV 或 textarea；没有 readonly、disabled、inert 或隐藏标记 | 暂停填入并显示提示，保留聊天草稿；不猜测其他输入框 |
| 异步填入 | 读取前后是同一编辑器和同一页面地址，且用户尚未写入草稿 | 丢弃这次填入请求，提示重新确认；不发送消息 |
| 展开/收起侧栏 | 唯一已知入口或 navigation 结构 | 仅停用对应侧栏入口，聊天旁入口按其自身契约工作 |
| 家庭桥接 | 当前上下文函数、档案和教材/章节控件齐备 | 清除旧共享选择和旧继续入口，显示同步暂停提示 |
| Tool | 明确点击 `/?tools=dd_family_study_readonly_v1`，宿主选择该工具 | 不注册、重绑、自动发送或保证真实模型会调用工具 |

网络中断或服务暂时失败时，已绑定档案的面板输入仅暂存在当前页面的内存中，隐藏旧输入并清空材料引用，停用填入与导出。恢复连接后须经过当前会话、教材范围及最终身份复核；同一账号/档案/revision才还原草稿，身份改变则丢弃暂存。不会把个人材料写入 localStorage、IndexedDB 或服务器。刷新或关闭页面会丢弃这份内存暂存，界面会明确提醒。

用户自己的主站聊天草稿保持，脚本不读取或改写历史聊天；切档后显示“历史聊天和聊天框草稿不会自动切换”及另开课本聊天的链接。已初始化伴学的页面在面板关闭时也响应家庭 storage 信号、可见性变化与定时会话复核；未打开伴学的页面不会提前枚举家庭资料。

键盘打开对话框、Esc关闭后回到原入口；成功填入后焦点停留在编辑器。移动端伴学按钮最小高度44px，表单字号16px；加载时移除宿主 viewport 的缩放限制，保留其他视口设置。合成触屏、320 CSS px重排及200% CSS zoom仅验证可自动检查的布局，不能代替实际手机双指缩放、软键盘和触摸反馈。

中文公式、离线课堂及三页A4复习卡沿用公开参考输出，打印仅使用隔离的公开内容iframe；聊天草稿、档案标识和面板个人输入不进入课堂/复习卡导出。下载“学习提纲”仍包含用户主动填写的材料，导出前继续核对身份。

本批服务源码候选 profile `reuse-runtime-study-host-compatibility-v1`为99文件。它包含family-bridge和此说明；主站study.js/CSS、许可证及vendor资源另外形成静态候选/回退集合，不能用服务源码包代替静态交付。旧98文件 B10服务候选及旧静态字节均保留，不降级数据库。没有生成可自动执行的正式代理配置或部署指令。

实际家庭验收必须记录桌面和手机的系统/浏览器版本、操作人、日期、逐项结果及问题；未知保持null，见[设备矩阵](../verification/B11-device-matrix-2026-11-08.json)。工程验证和真实设备反馈独立记录，真实反馈未取得时B11保持pending/open。
