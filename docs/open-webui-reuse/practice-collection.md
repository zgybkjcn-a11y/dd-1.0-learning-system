# 显式收藏错答与到期复习

B05 本地候选为家庭练习加入“收藏这次错答”：已判分的错答或部分正确作答可打开预览，核对原题、原始作答、辅助标记与题版后明确确认。预览与取消不写入收藏、复习卡或确认挑战；确认才保存。不会自动收藏、推断错因或请求模型诊断。工程验收见[B05独立记录](../verification/B05-practice-collection-2026-11-08.md)，真实家庭体验仍待验收。

## 题版与来源

schema 12 的 `012_practice_collection.sql` 为 `test_items` 增加可空的 `question_snapshot_json`。新会话在呈现题目时冻结题面、答案键、校验器、版本、知识目标与批准/归属信息；触发器拒绝修改这一字段。显示、提示、提交与判分前均比较出题快照和当前题版，漂移时停止操作，避免用新题面或答案解释旧作答。快照中的答案键不返回题面或收藏预览接口。

已有测验保持空快照并沿用原测验行为；它们不能被追认成具备原题冻结证据的收藏。预览会提示核对原记录并使用手动收藏，不能从当前题库猜补出题时的内容。旧题版仍存在且批准有效时，即使新增了其他版本，已保存的版本不会自动切换；原版本被改写或停用时阻止复习，收藏内的原题和作答仍保留供核对。

既有变式撤销契约继续保留：撤销前已经提交的作答可完成判分，但判分时仍要求题面、答案键、归属、目标及其他冻结字段一致；仅允许批准状态变为停用。未提交题项继续失效，不因此恢复投放或允许收藏。

## API 与写入边界

- `GET /api/v1/attempts/{attempt_id}/collection-preview`：只读返回当前档案的已判分错答、题版/作答关联及预览哈希。未判分、正确或无法确定的结果不能在此收藏。
- `POST /api/v1/attempts/{attempt_id}/collection`：要求 `confirmed=true`、`preview_sha256` 和 `Idempotency-Key`。客户端不能传题干、答案、目标或身份覆盖服务器记录；事务内重新核对题版、判分与预览哈希。
- `GET /api/v1/review-tasks`：保留原响应，新增各目标的 `saved_practice` 列表，含原题版本、收藏ID和当前可用性。只展示当前档案的有效收藏。
- `POST /api/v1/test-sessions`：新增可选 `mistake_id`。收藏复习必须指定对应复习卡，并核对收藏、目标、版本与可用性；不能用另一个题版替换收藏题。

收藏复用 `mistake_entries`、`mistake_sources` 的 `test_attempt` 来源和现有 `review_cards`。按作答来源唯一约束与SQLite写事务处理并发：同键重试或不同键双击只保留一条来源/收藏，不重排复习时间。确认响应丢失后，界面保留同一重试标识。已经撤回的收藏不会因重试恢复；判分或题版变化后须重新核对。

浏览器复用登录、CSRF及共享档案版本检查；数据库写事务还会再次核对当前档案与访问资格。另一个页面切换档案或撤销权限时，旧确认停止，界面清除原档案内容。缺少可信身份不会写入。

## 到期与辅助作答

复习卡按知识目标归并，多个收藏可共享同一张卡。新目标首次收藏安排为档案时区的次日08:00；已有卡沿用原状态和时间，不因再次收藏延期或重置。到期列表显示所选课本/章节的收藏原题，选择后使用原版本作答。一次符合条件的目标复习可以完成该目标本轮调度，不代表同目标的每条收藏都已经练过。

调度继续使用 `interval-v1`：首次独立复习正确从stage 0进入stage 1，延后2个本地自然日08:00；后续间隔为4、7、15、30天。独立错答回到relearning/stage 0，次日08:00再复习；stage 5及maintenance沿用既有维护门槛。参考的是作答提交日期及卡片冻结时区，不是浏览器时区或固定24小时加法。

提示后的作答显示“辅助练习”，不计入独立证据，也不推进或延期卡片；该目标仍可能出现在到期列表。B05没有增加手动延期按钮。四题升档、掌握证明与复习调度保持各自含义。

## 验证、交付与接续

所有验证使用合成题库/身份、临时数据库和浏览器ASGI请求拦截。新增测试入口为 `tests/test_practice_collection.py` 与 `tests/test_practice_collection_browser.py`，另运行直接相关的调度、共享档案、练习、发布清单和OpenAPI契约检查。手机与桌面的工程浏览器结果不代表家庭实机或家长反馈。

发布工具新增 `reuse-runtime-practice-collection-v1`（schema 12）；schema 11备用题profile与此前清单验证规则保留。新源码包只封装代码/文档/迁移，不含学生、教材或正式运行库。本批未构建镜像、迁移正式库、注册Tool或部署。

迁移是新增字段与触发器，保留所有旧行。未来如需回退应按实际发布包和备份维护规程执行；不删除新收藏，不清空快照，不自动逆迁移。旧代码无法提供B05入口与快照检查，不能声称回退后仍有此功能。
